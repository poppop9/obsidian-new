# thesis
当我们在人际关系中遇到困难或者在小的共同体中无法获得归属感时，首先应该考虑的是倾听更大的 [共同体](../21-Library/9-未知/共同体.md)。

# supports

# derives
倾听更大的共同体，就像烦闷时走出去，看看山，看看天空。置身于更广阔的天地之间，便会发现，原本困扰自己的那些烦恼，不过是如此渺小。

# contrast

# example
## 1）
例如，学生只看到“学校”这个共同体。也就是说，学校就是一切，我正因为有了学校才是“我”，这之外的“我”根本不可能存在。但是，在这个共同体中自然也会遇到某些麻烦，比如“我”有可能对于学校这个共同体不能产生“可以在这里”的归属感。

然后就会逃避到更小的共同体，例如家庭，并且还会躲在里面不愿出去，想要通过这样做来获得某种归属感。

但是，在这里希望你能关注的是“还有更多别的共同体”，特别是“还有更大的共同体”。如果学校中没有自己位置的话，还可以从学校“外面”找到别的位置，可以转学，甚至可以退学。

## 2）
例如，有人一旦退休便立即没了精神。因为被从公司这个共同体中分离出来，失去了头衔、失去了名片，成了无名的“平凡人”。

但是，这只不过是从公司这个小的共同体中被分离出来而已，任何人都还属于别的共同体。而且无论怎样，我们的一切都属于地球这个共同体，属于宇宙这个共同体。
