# thesis
如果一个人想获得完全自由，就不能被某种东西控制，他必须做到按照自己的价值行动、不再用别人的评价决定自己、接受别人可能不喜欢我的选择。

所以，能接受别人讨厌你，是你不再被别人控制的证明。所以可以简单概括为「自由就是能够接受被他人讨厌」。

# extends
“被讨厌”不是目的，而是即使有人讨厌我，我依然能够按照自己的原则生活。

# example
- 比如一个人想抽烟，他会认为“我想抽，所以我是自由的。”但实际上，他被烟控制了。
- 比如一个人想让所有人都喜欢他，那么他不自由，因为别人的评价控制着他的选择。
