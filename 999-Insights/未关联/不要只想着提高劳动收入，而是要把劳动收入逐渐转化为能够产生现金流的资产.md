你的财富增长，应该越来越依赖资产产生的现金流，让钱为你工作，而不是单纯依赖工资。

高薪工作只意味着两件事：你在为钱工作、你所支付的税收可能会增加。

# 路径对比
- 普通人的路径：工作 - 工资 - 消费 - 剩余一点钱 - 继续工作
- 理想的路径：工作 - 工资 - 留下部分钱 - 购买/创造资产 - 资产产生现金流 - 继续购买/创造资产 - 更多现金流 - 不依赖于工资

# 什么是资产？
这里的“资产”不是单纯指“值钱的东西”，关键是它能不能持续给你带来现金流？

| 东西    | 是否可能产生现金流   |
| ----- | ----------- |
| 自住房   | 通常 ❌        |
| 汽车    | 通常 ❌，还会产生支出 |
| 股票    | ✅ 股息/企业价值增长 |
| 出租房   | ✅ 房租        |
| 企业    | ✅ 利润        |
| 版权    | ✅ 版税        |
| 软件/产品 | ✅ 销售收入      |
