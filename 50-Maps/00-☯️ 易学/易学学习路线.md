# 路线说明
这是一条个人学习顺序，不代表知识对象之间的从属关系。学习过程中可以根据兴趣在象数、义理和历史三条方向之间往返。

# 第一阶段：建立整体认识
1. 阅读[书-易-0-周易](../../10-Sources/书/书-易-0-周易.md)，理解《周易》、经文和《易传》的关系。
2. 浏览[书-易-2-易经](../../10-Sources/书/书-易-2-易经.md)，先认识上经、下经和六十四卦，不急于逐卦深究。
3. 阅读[书-易-1-易传](../../10-Sources/书/书-易-1-易传.md)，观察后人如何解释并发展经文思想。

# 第二阶段：理解基本符号
1. 学习[阴阳](../../21-Library/2-模型/阴阳.md)与阴阳爻。
2. 学习[八卦](../../21-Library/2-模型/八卦.md)以及八卦相重形成六十四卦的结构。
3. 理解卦、爻、爻位、卦象和卦变等基本语言。

# 第三阶段：认识两种解释路径
1. 进入[象数易](解易传统/象数易.md)，理解卦象、爻位、数与图式如何参与解释。
2. 进入[义理易](解易传统/义理易.md)，理解变化、时位、中正、刚柔等思想。
3. 对照同一卦在象数与义理两种角度下的不同解释。

# 第四阶段：补充历史脉络
1. 通过[易学史](易学史.md)理解先秦、汉、魏晋、宋明与清代易学的主要变化。
2. 阅读具体人物和著作时，记录其所处时代、主要解释方法以及偏重的思想问题。

# 第五阶段：选择深入方向
- 偏重思想问题：继续学习[义理易](解易传统/义理易.md)，并关联[哲学](../02-🤔%20哲学/哲学.md)。
- 偏重符号和解释方法：继续学习[象数易](解易传统/象数易.md)。
- 偏重占筮和推演应用：从易学转入[术数](../01-🔮%20术数/术数.md)。
- 偏重历史演变：继续补充[易学史](易学史.md)。
