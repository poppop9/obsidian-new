# 反对赏罚式教育
赏罚式教育即做了恰当的事情就能够得到表扬，而如果做了不恰当的事情就会受到惩罚。在赏罚式教育之下会产生这样一种错误的生活方式，那就是“如果没人表扬，我就不去做好事”或者是“如果没人惩罚，我也做坏事”。

所以，阿德勒认为，一切与他人的交流（特别是育儿）都应该采取不批评也不表扬的方式。

# 表扬或批评背后的目的是什么？
表扬或者批评，其背后的目的都是操纵。

人表扬他人的目的就在于“操纵比自己能力低的对方”，其中既没有感谢也没有尊敬。

# 为什么表扬也不行？
因为表扬这种行为带有俯视感，含有“有能力者对没能力者所做的评价”的特点，无意之中营造了一种上下级的关系，也就是[纵向关系](../../999-Atoms/纵向关系.md)。

比如，我赞美你说“不错嘛，你做得很好”。你不觉得这种话有些别扭吗？你不觉得自己好像就被默认成了下位者吗？

# 为什么大家都希望得到表扬？
因为你生活在纵向关系中，你自己把自己看成下位者了，所以希望得到表扬。
