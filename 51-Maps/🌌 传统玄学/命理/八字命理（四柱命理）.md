# 什么是八字命理
八字命理，又称四柱命理、子平八字，是中国传统命理学的一种体系。它以一个人的出生年、月、日、时为基础，将出生时间转换为对应的 [天干地支](../../../21-Library/3-模型/天干地支.md)，形成“四柱八字”，再通过分析其中的 [阴阳](../../../21-Library/3-模型/阴阳.md)、[五行](../../../21-Library/3-模型/五行.md)、十神关系、格局旺衰、大运流年等，推演人的性格倾向、人生变化等。

# 四柱
一个人的出生时间分为年、月、日、时，称为“四柱”。

| 四柱  | 象征           |
| --- | ------------ |
| 年柱  | 祖上、家族背景、早年环境 |
| 月柱  | 父母、成长环境、社会基础 |
| 日柱  | 自身（日主）、婚姻关系  |
| 时柱  | 子女、晚年、未来发展   |

# 八字
四柱中，每一柱由两个字组成：天干 + 地支，所以一共会有八个字，这就是“八字”

| 四柱  | 组成      |
| --- | ------- |
| 年柱  | 年干 + 年支 |
| 月柱  | 月干 + 月支 |
| 日柱  | 日干 + 日支 |
| 时柱  | 时干 + 时支 |

# 八字基础：天干地支

## 天干

十天干：

```
甲 乙 丙 丁 戊 己 庚 辛 壬 癸
```

对应五行：

| 天干 | 五行 |
| --- | --- |
| 甲、乙 | 木 |
| 丙、丁 | 火 |
| 戊、己 | 土 |
| 庚、辛 | 金 |
| 壬、癸 | 水 |

---

## 地支

十二地支：

```
子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥
```

对应五行：

| 地支 | 五行 |
| --- | --- |
| 寅、卯 | 木 |
| 巳、午 | 火 |
| 辰、戌、丑、未 | 土 |
| 申、酉 | 金 |
| 亥、子 | 水 |

---

# 日主（日元）

八字分析中最核心的概念：

> 日主（日元）指的是出生当天的天干，代表“自己”。

例如：

```
日柱：甲辰
```

其中：

```
甲 = 日主
```

八字分析通常以日主为中心，观察其他五行与自己的关系。

例如：

```
其他五行 → 日主
日主 → 其他五行
```

由此形成：

- 生我
- 我生
- 克我
- 我克
- 同我

五种关系。

---

# 五行生克

八字建立在五行关系基础之上。

## 五行相生

```
木 → 火 → 土 → 金 → 水 → 木
```

关系：

- 木生火
- 火生土
- 土生金
- 金生水
- 水生木

---

## 五行相克

```
木 → 土 → 水 → 火 → 金 → 木
```

关系：

- 木克土
- 土克水
- 水克火
- 火克金
- 金克木

---

# 十神

## 什么是十神

十神是八字命理中的一个关系分类系统。

它以：

> 日主（自己）

为中心，根据其他五行与日主之间的生克关系进行分类。

五种基本关系：

| 关系 | 含义 |
| --- | --- |
| 生我 | 印 |
| 我生 | 食伤 |
| 克我 | 官杀 |
| 我克 | 财 |
| 同我 | 比劫 |

由于五行还分阴阳，因此每种关系又分为两类，共形成十种：

> 十神

---

# 十神分类

| 五行关系 | 十神 | 象征 |
| --- | --- | --- |
| 生我 | 正印、偏印 | 学习、知识、资源、保护 |
| 我生 | 食神、伤官 | 才华、表达、创造 |
| 我克 | 正财、偏财 | 财富、资源、经营 |
| 克我 | 正官、七杀 | 规则、压力、权力 |
| 同我 | 比肩、劫财 | 同辈、朋友、竞争 |

---

# 格局

格局是八字分析中的一种方法。

主要观察：

- 日主强弱
- 五行分布
- 十神组合

例如：

- 财格
- 官格
- 印格
- 食伤格

用于判断命局特点。

---

# 旺衰

旺衰指五行力量的强弱状态。

例如：

一个五行：

- 得季节支持
- 有根基
- 得其他五行帮助

则可能较旺。

反之则可能较弱。

传统命理会根据旺衰判断：

- 喜什么五行
- 忌什么五行

称为：

> 喜忌

---

# 大运与流年

八字不仅看出生时的固定结构，也会分析时间变化。

## 大运

大运指人生阶段性的运势周期。

传统命理通常以十年作为一个阶段。

---

## 流年

流年指每一年对应的天干地支变化。

通过流年与原八字之间的关系，分析一年中的变化。

# 定位

八字命理属于中国传统术数体系。

它建立在：

- 阴阳思想
- 五行理论
- 天干地支系统
- 时间观念

之上。

从文化研究角度看，它是一套传统的象数模型；从现代科学角度看，其预测功能尚未得到科学验证。
