# 亲和力是什么，有什么用？
亲和力是指一个人能够让别人感到舒服、放松、被理解、被接纳，并愿意主动与其建立关系的能力。

亲和力能够拉近距离、建立信任、让别人喜欢你，进而想要帮助你。

# 如何培养亲和力？（道）
## 1）专注于小小的喜悦
例如窗外洒进来的阳光、蔚蓝的天空。

## 2）感恩正能量事物
例如服务生送来正确的餐点。

## 3）利他主义
也就是真心为对方着想。

# 如何展现亲和力？（术）
## 1）同频与共鸣
人们天然偏好与自己相似的人，相似可以体现在观点、性格、背景、兴趣、生活方式、语言方式、呼吸节奏上

1）语言同步：用对方的词，而不是自己的词，

```
客户说“这个要多少钱​”​，你就不要说“价格”

当产品品牌名的首字母与自己的名字相同时，人们更有可能选择购买
```

2）肢体同步：在对方说话时，留意他自然停顿、换气的节奏，在这些空隙，配合着他呼吸的频率，轻微点头或小幅身体回应。这样对方会感到放松、被理解，进一步降低心理防线。

## 2）使用非语言
1）用轻松的身体语言敞开自己：姿势放松、不交叉双臂、自然露出手掌（手掌象征脆弱与真诚，会在潜意识里传达“我没有防备，也不会伤害你”）。

更多非语言内容可以参考[书-读心术](../../21-Library/0-条目/书/书-读心术.md)。

2）尽可能多的肢体接触：接触得越多，别人越会觉得我们值得信赖，也越容易建立合作关系。
```
温柔地触碰对方的前臂以强调某一点，或者引领对方入座，可以使对方感到舒服。

餐馆女服务员与顾客有身体接触时，顾客会给更多小费。
```

# 其他
## 测试你的亲和力
通过对「私人空间」的反应，判断你们的心理距离。

例如，找个喝对方一起喝水的机会，聊上几句后，假装不经意地把自己的杯子往对方那边稍微推推。
- 如果对方没有反应，表示你们之间的距离缩短了
- 如果对方把他的杯子移开了，表示他对你还抱有一定的距离感
