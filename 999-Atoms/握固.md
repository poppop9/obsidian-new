# 什么是握固？
握固是中国传统道家养生学与中医导引术中最古老、最简单、也最深奥的一种手印。它被誉为"养生第一印"，从新生婴儿的本能动作中被古人观察、提炼，成为固摄精气、安神定志的核心功法。

> 刚出生的婴儿，双手大多都是自然握成这个样子的，这就是天生的“握固”。

# 握固怎么做？
- 大拇指扣向掌心：将大拇指的指尖掐在无名指的指根处（即无名指与手掌交界处的横纹里）。
- 四指握拢：其余四指（食指、中指、无名指、小指）顺势包裹住大拇指，握成拳头。
- 力度适中：不用太用力，自然握紧即可，像握着一件珍宝一样。

# 握固有什么作用？
## 1. 固摄精气，防止耗散
无名指根部（"子位"）是气机门户之一，握固可关闭此门，起到 "固摄精气、安神定志" 之效。

## 2. 护住肝魂，安定心神
中医讲 "肝藏魂"。婴儿神智未开、阳气纯粹，本能握固以防"惊悸失魂"。

- 安抚神经、缓解焦虑
- 改善受惊后的心慌、手抖
- 助眠、减少多梦

## 3. 点燃少阳，激发一阳来复
子时对应足少阳胆经当令，胆属"少阳"。握固大拇指掐住无名指根部的"子位"，本质上是在"于至阴之中，唤醒一阳"，呵护并激发胆经这股刚萌发的少阳之气，使全身脏腑生机得以启动。

## 4. 滋水涵木，肝肾同养
- "子位"五行属水（对应肾水、藏精）。
- 胆、肝五行属木（对应生发之气）。
- 握固掐子位，借肾水滋养肝胆木气，实为 "滋水涵木" 之法，肝肾同补。

# 什么情况下适合握固？
- 受到惊吓、心慌焦虑，可以握固快速收摄心神、平复情绪
- 紧张、面试、上台前，可以稳定胆气、增强决断力（"胆主决断"）
- 情绪波动、易怒烦躁，可以平肝安魂、疏理气机
- 半夜惊醒、入睡困难、多梦易惊（尤其子时前后），握固可固护当令的胆经，安神再入睡
- 乘车、坐地铁，可以避免外界杂气扰乱心神
- 冬季外出、感到寒冷，可以保存阳气，减少阳气外散

# 什么情况下不适合握固？
- 饭后不适合，因为此时气血在脾胃，如果握固，气机会向四肢末端和肝胆经调动，激发少阳生发之气。两股力量方向相反，等于让脾胃"分心"，运化功能就会被削弱。而且肝胆属木克制脾土。
