# 太极
太极就是万事万物，万事万物都是太极。

- 阴是不易的，永远不会变，我们把它叫作常；
- 阳是变易的，瞬息万变，就是非常。

## 太极的由来
后人用心体会伏羲八卦，画出了太极图。

但太极这个名词是孔子说出来的。在孔子以前，没有人讲过什么是太极。“太”由两部分组合而成，一部分是“大”，一部分是“丶”。“大”字不必说，那一点就代表“小”。所以太极告诉我们，大极了，而且又小极了。“其大无外”，大到没有外面，够大了吧？“其小无内”，小到找不到里面，够小了吧？孔子非常了解伏羲，他说世界上有件东西大到没有外面，小到没有里面，那叫什么呢？最后他就想到叫太极。这个名字起得好！

# 两仪
两仪就是阳爻、阴爻。

# 四象
- 卯时，天是热的，地还是寒冷的，所以上面是阳爻，下面是阴爻，对应少阳
- 午时，天是热的，地也是热的，所以上下都是阳爻，对应老阳
- 酉时，天是寒的，地还是热的，所以上面是阴爻，下面是阳爻，对应少阴
- 子时，天是寒的，地也是寒的，所以上下都是阴爻，对应老阴

| 四象  | 符号  | 含义        |
| --- | --- | --------- |
| 少阳  | ⚎   | 阳中有阴，阳气初生 |
| 老阳  | ⚌   | 阳气最盛      |
| 少阴  | ⚍   | 阴中有阳，阴气初生 |
| 老阴  | ⚏   | 阴气最盛      |
