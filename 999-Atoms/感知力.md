# 什么是感知力？
感知力不是玄的东西，它就是我们本来就有的能力，只是被长时间忽略了。

# 与感知力相对的是什么力呢？
我认为是逻辑判断能力，也可以称之为经验。它们二者互为阴阳。

- 逻辑判断能力是理性的，是头脑层面，这种能力是你学过的知识、见过的案例，是头脑里的数据库。
- 感知力是感性的，是心层面，是你当下不经过头脑推理，而“直接知道”的能力。

```
逻辑判断能力：望诊看到“脸色苍白”，你脑子里调出了“气血虚”。

感知力：
- 你看到一个人，心里突然有种“这个人好累啊”的感觉，甚至你自己胸口都跟着发紧。
- 第一印象也是感知力的层面，有时候我们说不上来为什么，但就是对这个人有种亲切感，或者厌恶。
```

# 感知力怎么打开？
靠练“松”和“静”

不是学更多知识，而是先把头脑停一停。人太紧、太满的时候，感知力是被盖住的。现在大多数人都是麻木的，没有觉知。

最基础的方法就是我们第一次见面讲的觉察三角：从身体觉察开始，再慢慢到情绪和念头。

还有很多方法：我认为核心就是在当下的能力。比如每天花几分钟，不看手机，不做事，只是听周围的声音，闻空气里的味道，感受自己的呼吸。这个“不分析、只感受”的练习，就是打开感知力的基本功。

我喝茶的时候就去感受茶的香味层次，其实我们很多传统的修身养性活动都是可以训练感知力的

还可以去觉察，茶汤或者某种事物吃进身体后的变化，身体的感受，气的流动，这些都是日常可以做的

# 如何知道自己的感知力打开了？
有一个很简单的标志：你开始先感受到，然后才想明白，以前是脑子先动，现在是身体先有反应，然后你才意识到。

而且，你会越来越相信自己的第一感觉
