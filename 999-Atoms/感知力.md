# 什么是感知力？
感知力不是玄学，而是人本来就具备的一种能力，只是现代生活中，我们长期依赖头脑分析，忽略了它。

它指的是：不经过复杂的逻辑推理，而是通过身体和内在感受，直接感知当下信息的能力。

# 感知力与什么相对？
与感知力相对的，可以理解为逻辑判断能力。二者一阴一阳：

- 逻辑判断能力：偏理性，作用于头脑。它依赖于学习过的知识、积累的经验和见过的案例，本质上是调用已有信息进行分析和判断。
- 感知力：偏感性，作用于身心。它不需要先经过头脑推理，而是通过身体、情绪和内在感受，对当下的信息产生直接反应。

```
逻辑判断能力：望诊看到“脸色苍白”，你脑子里调出了“气血虚”。

感知力：
- 你看到一个人，心里突然有种“这个人好累啊”的感觉，甚至你自己胸口都跟着发紧。
- 第一印象也是感知力的层面，有时候我们说不上来为什么，但就是对这个人有种亲切感，或者厌恶。
```

# 感知力为什么会被盖住？
当一个人长期处于紧张、忙碌和头脑过度运转的状态时，注意力被头脑中的思考占满，就很难听见身体和内在的声音。

# 感知力怎么打开？
我们知道了感知力为什么会被盖住？我们就知道了如何打开感知力？

打开感知力不是首先学习更多知识，而是让头脑松下来、静下来，把注意力重新带回当下。核心可以概括为：
- 练“松”
- 练“静”
- 练习“在当下”
- 练习觉察

## 1）觉察
最基础的方法就是 [觉察](../21-Library/2-方法/觉察.md)。

## 2）不分析，只感受
每天花几分钟，不看手机、不做其他事情，只是感受当下，重点不是分析自己感受到了什么，而是先单纯地感受。
- 听周围的声音
- 闻空气中的味道
- 感受自己的呼吸
- 感受身体不同部位的状态
- 感受食物进入身体后的变化
- 感受身体内部细微的变化

# 打开感知力有什么好处？
当感知力逐渐恢复，你会越来越能够听见自己的第一反应，也更容易觉察到那些尚未被语言和逻辑整理出来的信息。

但不是盲目相信第一感觉，而是先感知 → 再思考 → 再验证。这样，感知力与逻辑判断能力就不是互相排斥，而是彼此配合。

# 如何知道自己的感知力打开了？
以前是头脑先动，现在是身体先有反应。也就是先感受到，然后才想明白。

你可能还没有想清楚“为什么”，身体却已经出现了某种感觉；过了一会儿，头脑才把这种感觉整理成语言和判断。
