# 什么是五时？
五时是 [五行](../../21-Library/3-模型/五行.md) 在时间维度上的映射，指的是一年时间循环中的五个阶段。

| 五行  | 五时  | 季节                | 特征                              |
| --- | --- | ----------------- | ------------------------------- |
| 木   | 春   | 春季                | 生发                              |
| 火   | 夏   | 夏季                | 旺盛、扩张、上升                        |
| 土   | 长夏  | 夏秋之间，夏末秋初（农历六月左右） | 化生、承载                           |
| 金   | 秋   | 秋季                | 收敛、肃降、[肃杀](../../21-Library/0-条目/词语/肃杀.md) |
| 水   | 冬   | 冬季                | 收藏、潜藏、下行                        |
# 长夏是什么？
长夏是五行体系为了对应“土”而加入的一个特殊季节。

土表示转化，所以长夏的特点是转化，你看 [五脏六腑](五脏六腑.md) 里的脾土的功能也是转化，所以它们就是可以归为一类。

# 五时划分
- 为什么春对应木？—— 因为春天的特点是草木发芽、阳气从地下向上升、生命开始启动，这种“向上、生长、扩展”的趋势，就是木性。
- 为什么夏对应火？—— 因为夏天气温最高、阳气达到极盛、万物快速生长，这种“旺盛、外放”的状态，就是火性。
- 为什么秋对应金？—— 因为秋天植物结果、生命开始收缩、阳气逐渐下降，正好对应金的收敛、肃杀、凝聚。
- 为什么冬对应水？—— 因为冬天万物进入休眠、能量藏于地下、生命保存力量等待下一轮循环，正好对应水的特点：向下、潜藏、蓄积
- 为什么多一个“长夏（土）”？—— 五行强调五种运动状态，而四季只有四个主要阶段，因此引入“长夏”作为季节转换和万物化生的阶段，使时间循环与五行结构对应。

# 五时要怎么养生？
## 春天：既要养阳，又要升发
春夏，阳气跑到身体表面（体表、四肢、毛孔）去抗御外邪、宣散汗液。导致身体内部（胃肠、脏腑）的阳气就相对不足了，呈现一种“内里虚寒”的状态。

所以，春夏，人反而容易拉肚子，吃冰凉的东西特别容易伤脾胃，就是因为“内里寒”。“养阳”是为了补充内里空虚的阳气，护住根本。

春天是万物复苏的季节，藏了一冬天的能量要破土而出，往上走、往外散。

如果春天不帮助阳气升发，阳气就会被“闷”在体内，变成“郁火”，人会感到头晕、乏力、昏昏欲睡（春困），这就是阳气升不起来的表现。

“养阳”是“升发”的物质基础。正因为阳气要往外、往上走，内里容易空虚，所以我们才要源源不断地在内里“温养”阳气，给阳气的升发提供源动力。

“升发”是阳气运动的方向，“养阳”是阳气运动的能量源泉。没有“养”，就无物可以“升”；没有“升”，“养”出来的阳气就会变成死水、上火。

如何做到“既养又升”？选择辛甘温：韭菜、生姜、葱、香菜。它们是“温”的，能温养内里的脾胃之阳（养阳）。它们又是“辛散”的，辛味能宣散、往外走，能带动阳气往外、往上运行（助升发）。

## 秋天：既要养阴，又要助收
秋冬时，大自然的阳气开始往地下收藏，人体的阳气也从体表退回到体内脏腑（所以冬天手脚冷，但胃口好、消化强）。

阳气收到里面容易"烧干"津液，所以要养阴（补充水分/阴液）。

梨、百合、银耳、山药、白萝卜、杏仁

## 冬天：既要养阴，又要养阳，还要助藏
冬天藏什么？藏阳气、藏精气、藏能量，为来年春天的"生发"储备燃料。

所以需要节制房事，中医认为过度消耗肾精会大伤元气。

什么是养阴？养阴不是吃寒凉，而是补充身体的物质、津液、精血，让身体"有料"、"滋润"、"不干燥"。比如吃枸杞、山药、桂圆、阿胶。

冬天还要温补肾阳：羊肉、牛肉、核桃、栗子、韭菜。为什么还要养阳？阳是给"藏"这个动作提供能量的，没有阳气，就没有"藏"的动力。所以冬天温补，不是为了让身体"热起来发散"，而是为了让身体有足够的阳气去"封藏"阴精。

所以冬天既不要伤阴，也不要伤阳。
