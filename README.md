# Folder
Source：能给你带来思考、洞见、可演化的内容 → 进入 Zettelkasten / Permanent
Reference：纯事实、工具说明、一次性资料 → 放在 Reference

# 分类
Tags 用于广义检索；Links 表达具体关系；Folders 以 PARA 为主。

# 笔记符号
`✓`
`⟡`
`¶`

### 导航类
- `_`：元数据文件
- `§`：节 / 区块 / MOC 分节
- `@`：人物 / 作者 / 机构 / 理论来源
- `+`：补充

### 思考状态类
- `!`：洞见 / 值得保留的结论
- `?`：问题 / 未决点 / 待验证
- `~`：暂定观点 / 草稿表达
- `⚠`：边界 / 例外 / 风险
- `※`：参考

### 关系类
- `→`：引出 / 支持 / 导致 / 推演
- `↔`：对照 / 互补 / 张力
- `↑`：上位抽象 / 原则化
- `↓`：下位实例 / 应用场景
- `×`：冲突 / 反驳 / 不兼容
