# 外物
## 13
**荃者所以在鱼，得鱼而忘荃；蹄者所以在兔，得兔而忘蹄；言者所以在意，得意而忘言。吾安得忘言之人而与之言哉？”**

捕鱼的竹篓只是捕鱼的工具，鱼已经捕到了，就不必再执着于竹篓；捕兔的陷阱只是抓兔子的工具，兔已经抓到了，就不必再执着于陷阱。语言只是表达思想的媒介，当真正领悟了其中的道理之后，就不应再拘泥于语言文字本身。我到哪里才能找到一个能够超越语言、直达真意的人，与他畅谈呢？

```
工具只是达到目的的手段，不是目的本身。语言只是传达意义的媒介，不是真理本身。真正重要的是“意”（道、真理、体验），而不是“言”（文字、概念、理论）。

“得鱼忘筌”这个成语就出自此处

筌：quán，用来捕鱼的竹器
蹄：兔罝、捕兔的网或陷阱
```
