# 正文
## 2.1

> **子曰：“为政以德，譬如北辰居其所而众星共之”**
> 
> 孔子说：“用道德来治理国政，自己便会像北极星一般，在一定的位置上，别的星辰都环绕着它”

```
孔子认为，治理国家不是靠“折腾”和“高压”，而是靠统治者自身的人格魅力，如果他本人技术过硬、为人正直、处事公平，他不需要天天盯着员工，大家也会自然而然地团结在他周围，朝一个目标努力
```

## 2.2

> **子曰：“诗三百，一言以蔽之，曰：‘思无邪’”**
> 
> 孔子说：“《诗经》三百篇，用一句话来概括它，就是‘思想纯正’”

```
诗三百 —— 《诗经》实有三百五篇，“三百”只是举其整数
```

## 2.3

> **子曰：“道之以政，齐之以刑，民免而无耻；道之以德，齐之以礼，有耻且格”**
> 
> 孔子说：“用政法来诱导他们，使用刑罚来整顿他们，人民只是暂时地免于罪过，却没有廉耻之心。如果用道德来诱导他们，使用礼教来整顿他们，人民不但有廉耻之心，而且人心归服”

## 2.4

> **子曰：“吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩”**
> 
> 孔子说：“我十五岁，有志于学问；三十岁，懂礼仪、说话做事都有把握；四十岁，掌握了各种知识，不致迷惑；五十岁，得知天命；六十岁，一听别人言语，便可以分别真假，判明是非；到了七十岁，便随心所欲，任何念头不越出规矩”

```
- 15 岁时觉醒了，不再是父母老师逼着学，而是自己发自内心地想通过学习改变命运、理解世界
- 30 岁时已经形成了独立的思想，能自立于社会，不是指的买车买房成家立业，而是不在人云亦云，有自己的思想和价值观，独立了
- 40 岁见过各种人，别人怎么忽悠你，你心里都有数。你明白了自己的局限性，不再纠结，不再怀疑人生
- 50 岁认清了自己的使命，知道努力固然重要，但是有些事是自己无法控制的，而是尽自己所能，不再强求结果
- 60 岁听到什么话都能心平气和，不生气，你知道别人为什么骂你，为什么夸你，你不再因为外界的评价而情绪波动
- 70 岁已经把道德和规矩刻进了骨子里，随心所欲做出来的事情都是恰好符合规矩的
```

## 2.5

> **孟懿子问孝。子曰：“无违”。樊迟御，子告之曰：“孟孙问孝于我，我对曰，无违”。樊迟曰：“何谓也？”。子曰：“生，事之以礼；死，葬之以礼，祭之以礼”**
> 
> 孟懿子向孔子问孝道。孔子说：“不要违背礼节”。不久，樊迟替孔子赶车子，孔子便告诉他说：“孟孙向我问孝道，我答复说，不要违背礼节”。樊迟道：“这是什么意思？”。孔子道：“父母活着，依规定的礼节侍奉他们；死了，依规定的礼节埋葬他们，祭祀他们”

## 2.6

> **孟武伯问孝。子曰：“父母唯其疾之忧”**
> 
> 孟武伯向孔子请教孝道。孔子道：“做爹娘的只是为孝子的疾病发愁”

```
做子女的，要做到让父母只为你的身体健康担忧，除此之外，不让他们为你操任何心

孟武伯 —— 仲孙彘，孟懿子的儿子，“武”是谥号
```

## 2.7

> **子游问孝。子曰：“今之孝者，是谓能养。至于犬马，皆能有养；不敬，何以别乎？”**
> 
> 子游问孝道。孔子说：“现在的所谓孝，就是说能够养活爹娘便行了。对于狗马都能够得到饲养；若不存心严肃地孝顺父母，那养活爹娘和饲养狗马怎样去分别呢？”

```
物质供养只是“孝”的最底层，而“敬”才是“孝”的灵魂

子游 —— 孔子学生，姓言，名偃，字子游，吴人，小于孔子四十五岁
养 —— “养父母”的“养”从前人都读去声，yàng
```

## 2.8

> **子夏问孝。子曰：“色难。有事，弟子服其劳；有酒食，先生馔，曾是以为孝乎？”**
> 
> 子夏问孝道。孔子道：“儿子在父母前经常有愉悦的容色，是件难事。有事情，年轻人效劳；有酒有肴，年长的人吃喝，难道这竟可认为是孝么？”

```
孝顺不是做给别人看的仪式，而是要让父母感受到你发自内心的愉悦 —— 最难的就在于给父母好脸色看。而不是仅仅是家里有重活，年轻人替长辈做了；有了好酒好菜，先紧着长辈吃。

馔 —— zhuàn，吃喝
曾 —— 音层，céng，竟也
```

## 2.9

> **子曰：“吾与回言终日，不违，如愚。退而省其私，亦足以发，回也不愚”**
> 
> 孔子说：“我整天和颜回讲学，他从不提反对意见和疑问，像个蠢人。等他退回去自己研究，却也能发挥，可见颜回并不愚蠢”

```
真正的进步，不在于你当众辩论赢了谁，而在于你私下里把道理琢磨透了，并把它变成了自己的本领。你总想着反驳别人，这其实干扰了对知识的吸收。颜回是先全盘接收，把老师的思想彻底装进自己的系统里，再去思考。

回 —— 颜回，孔子最得意的学生，鲁国人，字子渊
```

## 2.10

> **子曰：“视其所以，观其所由，察其所安。人焉廋哉？人焉廋哉？”**
> 
> 孔子说：“考查一个人所结交的朋友；观察他为达到一定目的所采用的方式方法；了解他的心情，安于什么，不安于什么。那么，这个人怎样隐藏得住呢？这个人怎样隐藏得住呢？”

```
看一个人现在在干什么，观察他做这件事经过的途径方法，他内心安于什么，什么状态能让他觉得踏实开心，你就能看到他真实的样子。例如这个人在捐钱，看他的钱是自己赚的，还是贪污的，看他捐钱是为了自己内心愉悦，还是为了四处炫耀

廋 —— sōu，隐藏，藏匿
```

## 2.11

> **子曰：“温故而知新，可以为师矣”**
> 
> 孔子说：“在温习旧知识时，能有新体会、新发现，就可以做老师了”

```
学习不是简单的堆砌。第一遍学的时候，我们往往只停留在表面。当你第二次、第三次去看同样的知识时，因为你的人生阅历变了、思维水平提高了，你会发现以前没看出来的深意。
```

## 2.12

> **子曰：“君子不器”**
> 
> 孔子说：“君子不像器皿一般”

```
一个真正的君子，不能像器具那样，只有一种固定的用途。

孔子认为，君子当然可以有具体的技能，但他不能仅仅满足于做一个只懂一门手艺的“技术员”，而是应该追求更高的“道”（道德、大局观、智慧），能够驾驭各种技能，而不是被技能所限制。但是“博学”是为了“通达”，而不是为了单纯的存储信息。
```

## 2.13

> **子贡问君子。子曰：“先行其言而后从之”**
> 
> 子贡问怎样才能做一个君子。孔子道：“对于你要说的话，先实行了，再说出来”

## 2.14

> **子曰：“君子周而不比，小人比而不周”**
> 
> 孔子说：“君子是团结，而不是勾结；小人是勾结，而不是团结”

```
周 —— 以当时所谓道义来团结人
比 —— bì，以暂时共同利害互相勾结
```

> 
> 孔子说：“只是读书，却不思考，就会受骗；只是空想，却不读书，就会缺乏信心”

```
学是思的基础，思是学的消化
```

## 2.16

> **子曰：“攻乎异端，斯害也已”**
> 
> 孔子说：“批判那些不正确的议论，祸害就可以消灭了”

## 2.17

> **子曰：“由！诲女知之乎！知之为知之，不知为不知，是知也”**
> 
> 孔子说：“由！教给你对待知或不知的正确态度吧！知道就是知道，不知道就是不知道，这就是聪明智能”

```
由 —— 孔子学生，仲由，字子路，小于孔子九岁
知 —— zhì，智慧
```

## 2.18

> **子张学干禄。子曰：“多闻阙疑，慎言其余，则寡尤；多见阙殆，慎行其余，则寡悔。言寡尤，行寡悔，禄在其中矣”**
> 
> 子张向孔子学求官职得俸禄的方法。孔子说：“多听，有怀疑的地方，加以保留；其余足以自信的部分，谨慎地说出，就能减少错误。多看，有怀疑的地方，加以保留；其余足以自信的部分，谨慎地实行，就能减少懊悔。言语的错误少，行动的懊悔少，官职俸禄就在这里面了”

```
面对不确定的事情，不要急于表态，不要盲目行动。就算你觉得自己懂了，说话做事也要留有余地，不要把话说死，不要把事做绝。一个人在社会上走得稳、走得远，往往不是因为他跑得最快，而是因为他犯错最少。

干禄 —— 干，求也，禄，旧时官吏的俸给
阙 —— quē
尤 —— yóu
行 —— xìng
```

## 2.19

> **哀公问曰：“何为则民服？”。孔子对曰：“举直错诸枉，则民服；举枉错诸直，则民不服”**
> 
> 鲁哀公问道：“要做些甚么事才能使百姓服从呢？”。孔子答道：“把正直的人提拔出来，放在邪曲的人之上，百姓就服从了；若是把邪曲的人提拔出来，放在正直的人之上，百姓就会不服从”

```
如果领导者提拔好人，大家就知道做好人有出路，社会风气就会变好。当正直的人掌权时，他们会制约和改变那些邪恶的人。百姓看到正义得到伸张，自然会对政权产生信任感。

哀公 —— 鲁君，姓姬，名蒋，定公之子，继定公而即位，在位二十七年
举 —— 提拔、任用
直 —— 正直的人，品行端正、有才能的人
错 —— 放置
枉 —— 心术不正、贪赃枉法的人
```

## 2.20

> **季康子问：“使民敬、忠以劝，如之何？”。子曰：“临之以庄，则敬；孝慈，则忠；举善而教不能，则劝”**
> 
> 季康子问道：“要使人民严肃认真，尽心竭力和互相勉励，应该怎么办呢？”。孔子说：“你对待人民的事情严肃认真，他们对待你的政令也会严肃认真了；你孝顺父母，慈爱幼小，他们也就会对你尽心竭力了；你提拔好人，教育能力弱的人，他们也就会劝勉了”

```
- 身教重于言教。领导者如果自己吊儿郎当、言而无信，下属就不会尊重你，你严肃对待工作，大家才不敢敷衍
- 想要员工忠诚，领导首先要关怀员工，你对员工好，员工才会把公司当成自己的事业来干
- 大家看到优秀者受奖，落后者受帮，整体氛围就会变得积极向上，人人都会互相勉励、努力工作

季康子 —— 季孙肥，鲁哀公时正卿，当时政治上最有权力的人
```

## 2.21

> **或谓孔子曰：“子奚不为政？”。子曰：“《书》云：‘孝乎惟孝，友于兄弟，施于有政’。是亦为政，奚其为为政？”**
> 
> 有人对孔子道：“你为什么不参与政治？”。孔子道：“《尚书》上说，‘孝呀，只有孝顺父母，友爱兄弟，把这种风气影响到政治上去’。这也就是参与政治了呀，为什么定要做官才算参与政治呢？”

```
但孔子一生都在积极寻找当官的机会，他确实很想为政，所以说这话感觉是在为自己辩解，哈哈哈

奚 —— 为什么
```

## 2.22

> **子曰：“人而无信，不知其可也。大车无輗，小车无軏，其何以行之哉？”**
> 
> 孔子说：“做为一个人，却不讲信誉，不知那怎么可以。譬如大车子没有安横木的輗，小车子没有安横木的軏，如何能走呢？”

```
大车 —— 古代用牛力的车叫大车
小车 —— 用马力的车叫小车
輗 —— ní，车辕前面有一道横木，就是驾牲口的地方，这个横木大车上的叫做鬲，鬲两头有关键（活销），輗就是鬲的关键
軏 —— yuè，车辕前面有一道横木，就是驾牲口的地方，这个横木小车上的叫做衡。衡两头有关键（活销），軏就是衡的关键
```

## 2.23

> **子张问：“十世可知也？”子曰：“殷因于夏礼，所损益，可知也；周因于殷礼，所损益，可知也。其或继周者，虽百世，可知也”**
> 
> 子张问：“今后十代的事情可以预先知道吗？”孔子说：“殷朝沿袭夏朝的制度，所废除的，所增加的，是可以知道的；周朝沿袭殷朝的制度，所废除的，所增加的，也是可以知道的。那么，假定有继承周朝而当政的人，就是以后一百代，也是可以预先知道的”

```
人性是不变的，所以社会运行的基本框架是不变的，而制度的改变通常是为了解决当下的现实问题，所谓的“损益”，就是补偏救弊。前一个朝代在哪方面做得过火了，后一个朝代必然会往回拉一拉。通过观察这种“钟摆式”的历史循环，他就能预判未来的调整方向
```

## 2.24

> **子曰：“非其鬼而祭之，谄也。见义不为，无勇也”**
> 
> 孔子说：“不是自己应该祭祀的鬼神，却去祭祀他，这是献媚。眼见应该挺身而出的事情，却袖手旁观，这是怯懦”
