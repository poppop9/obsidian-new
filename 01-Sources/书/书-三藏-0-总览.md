# 三藏是什么
三藏分为经、律、论

```
经
│
├── 金刚经
├── 心经
└── 华严经

律
│
├── 比丘戒
└── 僧团制度

论
│
├── 中论
├── 成唯识论
└── 大智度论
```

经就是佛陀讲的话。例如金刚经、心经、法华经、华严经、楞伽经、阿弥陀经

律就是戒律。例如和尚应该怎样生活、什么可以做、什么不能做

论是后来的高僧解释佛经。例如龙树、无著、世亲、玄奘，他们会写如何理解佛经
