# 故事
## 《道德经》的由来
司马迁的《史记·老子韩非列传》记载，老子在周朝国家图书馆当馆长，看到周朝不行了，决定跑路，骑青牛出关隐居。到了函谷关，遇到了粉丝兼守关长官尹喜死活拦着不让他走。尹喜说：“您都要隐居了，勉强为我写本书吧！”，老子迫不得已，写了分上下两篇、五千多字的《道德经》。

当然，后续考古发现，这个故事有很多漏洞，其实司马迁自己都搞不清楚老子是谁。司马迁自己说“老子，隐君子也”，意思是老子是个隐士，我也搞不太清楚他到底是谁。

学术界的普遍共识认为《道德经》里的很多名言，最初可能是古代隐士、智者们口口相传的民间哲学谚语。只是老子把这些谚语进行了收集、整理，并加入了自己深刻的哲学思考。后来，他的弟子以及一代代信奉道家思想的人，又不断地往里面补充、修改。直到战国末期到西汉初年，这本书才最终定型为我们今天看到的“五千言”版本。
