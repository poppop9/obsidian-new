
# 共同体感觉
```
共同体感觉
├── 归属感
├── 他者关怀
├── 合作意识
├── 贡献意识
└── 把他人视为伙伴而非敌人
```

**找到共同体感觉的路径**：主动付出 → 感觉自己对他人有用 → 体会到自我价值 → 获得生活的勇气 → 找到在共同体中的位置。

**归属感**
- 误区：认为只要加入一个组织就有归属感、认为只要别人接纳我、爱我，就有归属感。
- 正确定义：归属感来自于我对共同体有益的主观感觉，它是通过主动去爱赢回来的（我能帮别人做什么、我能为团队贡献什么），当你开始付出，当你感觉到自己对他人有用时，你自然就找到了自己在共同体中的位置。共同体感觉是人际关系的最终目的。

**自我中心主义**：认为自己是世界的中心，觉得别人的好理所当然，永远在等待别人来服务你，而不是主动去建立关系，一旦别人没有满足期待，你就愤怒、失望。

# 实现共同体感觉的三大支柱
**自我接纳**
- 自我接纳不是自我肯定。
- 反面案例：明明自己不行，还骗自己说我能行。
- 案例：做不到，就诚实地接受这个做不到的自己。

**他者信赖**
- 他者信赖是不附加任何条件的无条件相信。
- 他者信赖是搞好人际关系和构建横向关系的一种手段，如果你并不想与那个人搞好关系的话，那你可以选择不信赖。
- 与信用的区别：信用有附加条件，例如从银行贷款，就必须提供某些抵押。

**他者贡献**
- 他者贡献是为了能够体会到自身的价值，对伙伴给予影响、作出贡献。
- 他者贡献不是自我牺牲（为了他人牺牲自己的人生，这是过度适应社会的表现）。

# 什么是共同体感觉？
把他人看作伙伴，并能够从中感到“自己有位置”的状态，能够感到自己在为伙伴们做着贡献。这种感觉就叫共同体感觉。

# 共同体的范围是什么？
大多数人提到“共同体”这个词，想到的范围会是家庭、学校、单位、地域社会之类，但阿德勒指的是从过去到未来，甚至包括宇宙整体在内的“一切”。

# “拼命寻求认可”反而是以自我为中心
一般来说，说到“以自我为中心的人”，都会认为是残暴蛮横的人、自私任性的人、破坏和谐的人。

但其实，受认可欲求束缚的人也是极其以自我为中心的人。

为什么呢？因为认可欲求的实质是他人如何关注自己、如何评价自己？受这种认可欲求束缚的人看似在看着他人，但实际上眼里却只有自己。失去了对他人的关心而只关心“我”，也就是以自我为中心。

凡是执著于“我”的人都是以自我为中心的。所以，必须把“对自己的执著”换成“对他人的关心”。

我们首先是作为共同体的一员从属于共同体，能够感觉到在共同体中有自己的位置，也就是拥有归属感，这是人的基本欲求。

在与他人接触的时候总是会想：“这个人给了我什么？”但是，这种期待并不会每次都能被满足，因为“别人并不是为了满足你的期待而活”。因此，当期待落空的时候，他们往往会大失所望并感觉受到了极大的屈辱，而且还会非常愤慨，产生诸如“那个人什么也没有为我做”“那个人辜负了我的期望”或者“那个人不再是朋友而是敌人”之类的想法。

我们都在寻求归属感。但是，阿德勒心理学认为归属感不是仅仅靠在那里就可以得到的，它必须靠积极地参与到共同体中去才能够得到。

什么是积极地参与呢？就是直面三大“人生课题”。

但是，无论是你还是我，我们都不是世界的中心，必须用自己的脚主动迈出一步去面对人际关系课题；不是考虑“这个人会给我什么”，而是要必须思考一下“我能给这个人什么”。这就是对共同体的参与和融入。

您是说只有付出了才能够找到自己的位置？是的。归属感不是生来就有的东西，要靠自己的手去获得。
