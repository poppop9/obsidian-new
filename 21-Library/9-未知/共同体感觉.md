# old 笔记
**找到共同体感觉的路径**：主动付出 → 感觉自己对他人有用 → 体会到自我价值 → 获得生活的勇气 → 找到在共同体中的位置。

**归属感**
- 误区：认为只要加入一个组织就有归属感、认为只要别人接纳我、爱我，就有归属感。
- 正确定义：归属感来自于我对共同体有益的主观感觉，它是通过主动去爱赢回来的（我能帮别人做什么、我能为团队贡献什么），当你开始付出，当你感觉到自己对他人有用时，你自然就找到了自己在共同体中的位置。

**自我中心主义**：认为自己是世界的中心，觉得别人的好理所当然，永远在等待别人来服务你，而不是主动去建立关系，一旦别人没有满足期待，你就愤怒、失望。

# 什么是共同体感觉？
阿德勒说的共同体感觉，是一种主观心理状态，核心有两个。

## 1）归属意识
感觉自己属于共同体，是整体的一部分。

表现为：
- 主动参与共同体、愿意融入共同体

## 2）伙伴意识
把他人看作平等的伙伴，而不是满足自己需求的工具。

表现为：
- 从“别人能给我什么”转变为“我能为别人贡献什么”
- 公司给我多少钱？领导有没有认可我？→ 我能解决什么问题？我能创造什么价值？
- 他为什么没有主动找我？他是不是不在乎我？→ 我能不能主动关心一下他？我能不能给他一些支持？

# 共同体的范围是什么？
大多数人提到“共同体”这个词，想到的范围会是家庭、学校、单位、地域社会之类，但阿德勒指的是从过去到未来，甚至包括宇宙整体在内的“一切”。

# 为什么要实践共同体感觉呢？
实践共同体感觉是为了获得 [归属感](归属感.md)。我们都在寻求 [归属感](归属感.md)，这是人的基本欲求。但是，阿德勒心理学认为归属感不是仅仅靠在那里就可以得到的，它必须靠培养共同体感觉获得。

## 2）培养三大心理能力
自我接纳
- 自我接纳不是自我肯定。
- 反面案例：明明自己不行，还骗自己说我能行。
- 案例：做不到，就诚实地接受这个做不到的自己。

他者信赖
- 他者信赖是不附加任何条件的无条件相信。
- 他者信赖是搞好人际关系和构建横向关系的一种手段，如果你并不想与那个人搞好关系的话，那你可以选择不信赖。
- 与信用的区别：信用有附加条件，例如从银行贷款，就必须提供某些抵押。

他者贡献
- 他者贡献是为了能够体会到自身的价值，对伙伴给予影响、作出贡献。
- 他者贡献不是自我牺牲（为了他人牺牲自己的人生，这是过度适应社会的表现）。

## “拼命寻求认可”反而是以自我为中心
一般来说，说到“以自我为中心的人”，都会认为是残暴蛮横的人、自私任性的人、破坏和谐的人。

但其实，受认可欲求束缚的人也是极其以自我为中心的人。

为什么呢？因为认可欲求的实质是他人如何关注自己、如何评价自己？受这种认可欲求束缚的人看似在看着他人，但实际上眼里却只有自己。失去了对他人的关心而只关心“我”，也就是以自我为中心。

凡是执著于“我”的人都是以自我为中心的。所以，必须把“对自己的执著”换成“对他人的关心”。
