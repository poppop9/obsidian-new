# 什么是五运六气
五运六气是中医学基于[天干地支](../3-模型/天干地支.md)建立的一套时间变化模型，用于研究一年中自然气候、人体生理和疾病流行规律之间的关系。它认为天地之气会随着时间不断变化，而这些变化会影响自然环境，也会影响人体健康。

五运六气分为五运和六气，二者共同决定一年的气候特点和疾病倾向。
- 五运：反映天之气（天干）
- 六气：反映地之气（地支）

# 五运
## 什么是五运
五运是五行之气在一年中的运行状态。包括木运、火运、土运、金运、水运。每一年都会有一种五运作为这一年的主运（中运）。

## 五运如何确定
五运由天干决定，其依据就是「天干五合」

| 天干 | 五运 |
|------|------|
| 甲、己 | 土运 |
| 乙、庚 | 金运 |
| 丙、辛 | 水运 |
| 丁、壬 | 木运 |
| 戊、癸 | 火运 |
**例如**
- 甲某年 → 土运
- 丙某年 → 水运
- 戊某年 → 火运

## 太过与不及
每一种五运还有强弱之分，分为太过、不及。

**判断规则**
- 阳干 → 太过
- 阴干 → 不及

**例如**
- 丙 → 阳干 → 太过
- 辛 → 阴干 → 不及

# 六气
## 什么是六气
六气是自然界一年中六种主要气候变化。

包括：

- 风
- 寒
- 暑
- 湿
- 燥
- 火

它们对应一年不同阶段的气候特点。

---

## 六气如何确定

六气由**地支**决定。

因此：

- 天干决定五运
- 地支决定六气

最终形成：

```text
某一年
│
├── 天干
│     ↓
│   五运
│
└── 地支
      ↓
    六气
```

---

# 五运与六气的关系

五运代表整体五行之气的运行。

六气代表一年中气候变化的表现。

两者共同组成：

> 五运六气

例如：

```text
丙午年

丙
↓
水运太过

午
↓
对应六气

↓

综合分析当年的气候特点、人体变化及疾病趋势。
```

---

# 五运六气的用途

五运六气主要用于：

- 研究气候变化
- 推测疾病流行趋势
- 指导中医辨证施治
- 预测某一年容易出现的病证特点
- 分析人与自然的对应关系

它强调：

> 人体与自然环境相互影响，不同年份可能具有不同的气候偏性，因此养生和治疗也应因时而变。
