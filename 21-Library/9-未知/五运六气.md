# 什么是五运六气
五运六气是中医学基于[天干地支](../3-模型/天干地支.md)建立的一套时间变化模型，用于研究一年中自然气候、人体生理和疾病流行规律之间的关系。

五运六气认为天地之气会随着时间不断变化，而这些变化会影响自然环境，也会影响人体健康，因此养生和治疗也应因时而变。

# 五运
## 什么是五运
五运是五行之气在一年中的运行状态。包括木运、火运、土运、金运、水运。每一年都会有一种五运作为这一年的主运（中运）。

## 五运如何确定
五运由天干决定，其依据就是「天干五合」

| 天干 | 五运 |
|------|------|
| 甲、己 | 土运 |
| 乙、庚 | 金运 |
| 丙、辛 | 水运 |
| 丁、壬 | 木运 |
| 戊、癸 | 火运 |
**例如**
- 甲某年 → 土运
- 丙某年 → 水运
- 戊某年 → 火运

## 太过与不及
每一种五运还有强弱之分：太过、不及。

**判断规则**
- 阳干 → 太过
- 阴干 → 不及

**例如**
- 丙 → 阳干 → 太过
- 辛 → 阴干 → 不及

## 案例分析
### 1）丙午年
丙辛合化水，丙是阳干，所以是「水运太过」。

- 水自身
	- 寒性增强、润下增强（水湿偏重）、收藏增强（阳气升发受限）、流动失常（容易出现泛滥、停滞）
	- 天地水气偏盛，气候出现偏寒、偏湿变化。
	- 人体顺应自然，产生相应影响。原本水不足的人，反而可以趋向平衡。原本寒湿、脾虚的人，会寒湿加重、脾胃负担增加、运化能力下降。
- 火受制
	- 畏寒
	- 手脚冷
	- 精神动力不足
- 木可能偏旺
	- 肝气偏盛
	- 生发之性增强
	- 情绪波动
	- 气机不畅
- 金被消耗
	- 肺气不足
	- 防御能力下降
- 土受损
	- 脾胃运化下降
	- 湿气停留
	- 食欲下降
	- 腹胀
	- 大便偏稀

### 2）丁未年
丁壬合化木，丁为阴干，所以是「木运不及」。

- 木本身
	- 木气升发不利，阳气升发不利。
	- 人容易疲劳，早晨起不来。
	- 清阳不能上达于头，导致头部气血失于正常濡养，会头晕。
	- 想发泄情绪，但气机被堵，发泄不出来。
- 土被克制
	- 脾胃可以出问题
- 火生不起来
	- 供血不足，引起中风

# 六气
## 什么是六气
六气是自然界一年中六种主要气候变化。

包括：

- 风
- 寒
- 暑
- 湿
- 燥
- 火

它们对应一年不同阶段的气候特点。

## 六气如何确定
六气由地支决定。

因此：

- 天干决定五运
- 地支决定六气

最终形成：

```text
某一年
│
├── 天干
│     ↓
│   五运
│
└── 地支
      ↓
    六气
```
