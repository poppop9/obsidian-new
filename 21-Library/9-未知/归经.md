# 什么是归经
归经是药物对人体某些脏腑、经络系统所表现出的选择性作用。简单来说，就是判断一味药“主要作用于身体哪个系统”。
- 归：归属、归入
- 经：经络（也包括经络所联系的脏腑系统）

判断标准来自古人长期食用后观察到的身体反应，不是理论推导

一个食物往往归多条经 —— 例如生姜归肺经、脾经、胃经

| 火          | 症状            | 对应食物           |
| ---------- | ------------- | -------------- |
| **心火**     | 口腔溃疡、舌尖红、心烦失眠 | 莲子心（苦寒，归心经）    |
| **肝火**     | 眼睛红肿、暴怒、头胀痛   | 菊花（辛甘苦微寒，归肝肺经） |
| **胃火**     | 口臭、牙龈肿痛、便秘    | 石膏、绿豆（甘寒，归胃经）  |
| **肺火**     | 干咳、喉咙痛、鼻干     | 梨（甘凉，归肺胃经）     |
| **肾火（虚火）** | 腰酸、盗汗、手脚心热    | 枸杞、桑葚（甘平，归肾肝经） |

| 补                | 食物  | 四气五味 + 归经     |
| ---------------- | --- | ------------- |
| **补脾气**（消化差、疲劳）  | 山药  | 甘平，归**脾**肺肾经  |
| **补肺气**（气短、容易感冒） | 黄芪  | 甘温，归**肺**脾经   |
| **补肾精**（腰酸、早衰）   | 黑芝麻 | 甘平，归**肾**肝大肠经 |
| **补肝血**（眼干、月经少）  | 当归  | 甘辛温，归**肝**心脾经 |
| **补心血**（失眠、心悸）   | 桂圆  | 甘温，归**心**脾经   |


# 脏
实心，藏精气，属阴

| 脏     | 五行  | 核心功能              |
| ----- | --- | ----------------- |
| **肝** | 木   | 疏泄气机、藏血、主筋、开窍于目   |
| **心** | 火   | 主血脉、神志（意识思维）、开窍于舌 |
| **脾** | 土   | 运化、统血、主肌肉、开窍于口    |
| **肺** | 金   | 主气、主呼吸、主皮毛、开窍于鼻   |
| **肾** | 水   | 藏精、主骨、主生殖发育、开窍于耳  |

# 腑
空心，传导消化，属阳

脏和腑是一对一配合的，互为表里。所以当我们说一个食物"归肝经"，往往也会同时影响到胆

|腑|对应的脏|
|---|---|
|**胆**|肝|
|**小肠**|心|
|**胃**|脾|
|**大肠**|肺|
|**膀胱**|肾|
|**三焦**|心包（特殊）|
