# 什么是五时
五时是 [五行](../3-模型/五行.md) 在时间维度上的映射，指的是一年时间循环中的五个阶段。

| 五行  | 五时  | 季节                | 特征                              |
| --- | --- | ----------------- | ------------------------------- |
| 木   | 春   | 春季                | 生发                              |
| 火   | 夏   | 夏季                | 旺盛、扩张、上升                        |
| 土   | 长夏  | 夏秋之间，夏末秋初（农历六月左右） | 化生、承载                           |
| 金   | 秋   | 秋季                | 收敛、肃降、[肃杀](../0-条目/词语/肃杀.md) |
| 水   | 冬   | 冬季                | 收藏、潜藏、下行                        |
**补充说明**
- 长夏是五行体系为了对应“土”而加入的一个特殊季节。
- 怎么理解长夏呢？—— 长夏的特点是转化，你看 [五脏六腑](五脏六腑.md) 里的脾土的功能也是转化，所以它们就是可以归为一类。

# 五时划分
- 为什么春对应木？—— 因为春天的特点是草木发芽、阳气从地下向上升、生命开始启动，这种“向上、生长、扩展”的趋势，就是木性。
- 为什么夏对应火？—— 因为夏天气温最高、阳气达到极盛、万物快速生长，这种“旺盛、外放”的状态，就是火性。
- 为什么秋对应金？—— 因为秋天植物结果、生命开始收缩、阳气逐渐下降，正好对应金的收敛、肃杀、凝聚。
- 为什么冬对应水？—— 因为冬天万物进入休眠、能量藏于地下、生命保存力量等待下一轮循环，正好对应水的特点：向下、潜藏、蓄积
- 为什么多一个“长夏（土）”？—— 五行强调五种运动状态，而四季只有四个主要阶段，因此引入“长夏”作为季节转换和万物化生的阶段，使时间循环与五行结构对应。
