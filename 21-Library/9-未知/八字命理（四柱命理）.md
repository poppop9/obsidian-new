# 什么是八字命理
八字命理，又称四柱命理、子平八字，是中国传统命理学的一种体系。它以一个人的出生年、月、日、时为基础，将出生时间转换为对应的 [天干地支](../../../21-Library/3-模型/天干地支.md)，形成“四柱八字”，再通过分析其中的 [阴阳](../../../21-Library/3-模型/阴阳.md)、[五行](../../../21-Library/3-模型/五行.md)、十神关系、格局旺衰、大运流年等，推演人的性格倾向、人生变化等。

# 四柱
一个人的出生时间分为年、月、日、时，称为“四柱”。

| 四柱  | 象征           |
| --- | ------------ |
| 年柱  | 祖上、家族背景、早年环境 |
| 月柱  | 父母、成长环境、社会基础 |
| 日柱  | 自身（日主）、婚姻关系  |
| 时柱  | 子女、晚年、未来发展   |

# 八字
四柱中，每一柱由两个字组成：天干 + 地支，所以一共会有八个字，这就是“八字”

| 四柱  | 组成      |
| --- | ------- |
| 年柱  | 年干 + 年支 |
| 月柱  | 月干 + 月支 |
| 日柱  | 日干 + 日支 |
| 时柱  | 时干 + 时支 |

# 日主（日元）
日主（日元）指的是出生当天的天干，代表“自己”。八字分析通常以日主为中心，观察其他五行与自己的关系。

例如，你的日柱是甲辰，那么“甲”就是日主。

# 十神

## 什么是十神
十神是八字命理中的一个关系分类系统。它以日主为中心，根据其他五行与日主之间的生克关系进行分类。由于五行还分阴阳，因此每种关系又分为两类，共形成十种，所以叫十神。

## 十神分类

| 五行关系 | 十神    | 象征                   |
| ---- | ----- | -------------------- |
| 生我   | 正印、偏印 | 父母、贵人、公司、学习、知识、资源、保护 |
| 我生   | 食神、伤官 | 才华、表达、创造             |
| 我克   | 正财、偏财 | 财富、资源、经营             |
| 克我   | 正官、七杀 | 规则、压力、权力             |
| 同我   | 比肩、劫财 | 同辈、朋友、竞争             |

# 格局
格局是八字分析中的一种方法。

主要观察：

- 日主强弱
- 五行分布
- 十神组合

例如：
- 财格
- 官格
- 印格
- 食伤格

用于判断命局特点。

# 旺衰
旺衰指五行力量的强弱状态。

例如：
一个五行：
- 得季节支持
- 有根基
- 得其他五行帮助

则可能较旺。

反之则可能较弱。

传统命理会根据旺衰判断：

- 喜什么五行
- 忌什么五行

# 大运与流年
八字不仅看出生时的固定结构，也会分析时间变化。

## 大运
大运指人生阶段性的运势周期。

传统命理通常以十年作为一个阶段。

## 流年
流年指每一年对应的天干地支变化。

通过流年与原八字之间的关系，分析一年中的变化。
