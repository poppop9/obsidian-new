# 什么是五色
五色是五行体系在颜色属性上的映射，指青、赤、黄、白、黑五种颜色。古人认为，颜色不仅是视觉现象，也反映了自然界阴阳变化和五行之气的状态。

# 五色与五行对应关系

| 五行  | 五色  | 特征    |
| --- | --- | ----- |
| 木   | 青   | 生发、成长 |
| 火   | 赤   | 旺盛、热烈 |
| 土   | 黄   | 承载、调和 |
| 金   | 白   | 收敛、肃降 |
| 水   | 黑   | 收藏、潜藏 |

# 五色的含义

## 青色 → 木
青色代表生命萌发和成长。东方日出，万物生长，因此青色对应木。

## 赤色 → 火
赤色接近火焰的颜色，代表热烈和旺盛。火具有向上、扩散的特点，因此赤色对应火。

## 黄色 → 土
黄色来源于土地的颜色。土地孕育万物，具有承载和化生的作用，因此黄色对应土。

## 白色 → 金
白色具有清肃、纯净的特点。秋天万物成熟，金气收敛，因此白色对应金。

## 黑色 → 水
黑色代表深沉、幽暗。水向下流动，并具有收藏、潜藏的特点，因此黑色对应水。
