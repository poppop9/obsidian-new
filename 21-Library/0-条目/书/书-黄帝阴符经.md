# 版本
**《黄帝阴符经》在流传的过程中，正文字数和具体的字词有很大差异，可能原因如下**
1. 《黄帝阴符经》是一部“奇书”，道教用来修炼内丹，兵家用来打仗谋略，儒家用来讲理学。因为各家的目的不同，他们在传抄时，会有意无意地改动个别字词，以符合自己门派的理论。
2. 古人写书是没有标点符号的，全靠读者自己去“句读（dòu）”。因为断句不同，句子的意思甚至结构全变了。
3. 《黄帝阴符经》成书很早（大概在南北朝到唐代初年之间），在没有印刷术的时代，全靠手抄和石碑刻字。几百年来，甲抄给乙，乙抄给丙，很容易抄错
4. 古代写字不能和当朝皇帝的名字重字。比如唐代皇帝叫李世民，如果正文里有“民”字，就必须改成“人”字。这就导致不同朝代抄出来的版本，字词不一样。

**《黄帝阴符经》目前主流有两个版本**
- 短本（约 300 字左右）：很多学者和修道之人认为这才是真正的古本正文
- 长本（约 400 字左右）： 在短本的结尾处，又多出了一段一百多字的内容
- 后世很多学者（包括南宋的大儒朱熹）考证认为，长本多出来的那 100 多字，其实是古代某个注释者写的“读后感”或“注解”。但在古代抄书的时候，抄书人没搞清楚，把注解和正文抄混在了一起，当成正文流传下来了。

# 上篇
> [!NOTE]
> 上篇：讲“道”的规律，讲世界是怎么运转的。

**观天之道，执天之行，尽矣。**

观察天的运行规律，掌握天道的运作方式，这就是对“道”的彻底认识。

```
观察万事万物背后的那个"规律"，然后跟着它走，不要跟它对着干。 

- 你种庄稼，春天播种秋天收获，这就是“天道”。你非要在冬天种麦子，那就是找死。 
- 饥来吃饭，困来眠
```

**天有五贼，见之者昌。五贼在心，施行于天。宇宙在乎手，万化生乎身。**

天道中存在五种“贼”，能够识破它们的人，就能兴盛昌隆。这五个“贼”其实根植于人的内心，却能够影响天道的运作。如果能掌握内心，就能掌控天地万物的演化。

```
贼：不是小偷，而是代表一种损耗你的力量、破坏平衡的因素。

用一个比喻：你抽烟，享受它带给你的快感，但最终是这根烟在消耗你（肺癌），这就是“贼”。你以为你在用它的能量，其实是它在盗你的命。 你如果不想被烟“贼”死，你就要断掉它，而这个“断”的动作，就是你用“心”反制了“天”。 
```

**天性，人也。人心，机也。立天之道，以定人也。**

“天性”就是人的本性；人的内心则是万变之机。确立天道的法则，就是为了使人能够安身立命。

**天发杀机，移星易宿；地发杀机，龙蛇起陆；人发杀机，天地反覆。天人合发，万变定基。**

当天道生出杀伐之意时，星辰的轨迹就会发生变化；当地脉涌动时，龙蛇之气会从地底升起；当人心起了杀念，天地之间都会动荡翻覆；当天地与人心同时引发杀机，世间万象的根基也会因此重新确立。

```
真动了那个心念，能量是巨大的。 
```

# 中篇
**性有巧拙，可以伏藏。九窍之邪，在乎三要，可以动静。**
**火生于木，祸发必克；奸生于国，时动必溃。知之修炼，谓之圣人。**
**天生天杀，道之理也。天地，万物之盗；万物，人之盗；人，万物之盗。三盗既宜，三才既安。**
**故曰：食其时，百骸理；动其机，万化安。**

人的本性有聪慧也有愚拙，这是可以隐藏或修炼的。人身上的九窍（眼耳鼻口等）若生出邪气，往往根源于“三要”（上中下丹田或心、肝、肾三处），通过调动动静之机，便可制御这些邪气。
火由木生，意味着隐患在内部慢慢积聚，一旦爆发，必将造成克害；奸诈之人一旦在国家中滋生，等到时局动荡时，国家必然崩溃。能够洞察这些运行之理，并加以修炼实践的人，就是所谓的“圣人”。
天的生与杀，都是道的自然法则。天地之间盗取能量，孕育万物；万物则从天地中汲取精气而得以存在，而人又从万物中获取生存所需，养活自身。这种彼此“盗取”、相互依存的关系称为“三盗”，当这三者（天地、人、万物）的关系协调得当，天地人这“三才”也就和谐安定了。
所以说：“按照时令饮食，身体自然调和；把握时机行动，万物变化也会归于安稳。”

# 下篇
**人知其神之神，不知其不神之所以神也。**

人若了解内在的“神性”，就能真正发挥出神奇的力量，但多数人不知道那“无神”之中的“神”，所以不能真正做到神明。

**日月有数，大小有定，圣功生焉，神明出焉。其盗机也，天下莫能见，莫能知。君子得之固躬，小人得之轻命。**

日月运行是有规律的，大小之数、明暗之变，也都有一定的法度。圣人之功，就是从这些规律中产生，神明的智慧，也是从中体现。然而这其中的“盗机”，即天地运行和变化之机，世人几乎看不见、也难以察觉。君子若能把握这个“机”，会谨慎地修身守道，而小人若得其机，则会轻率妄为，反而贻害性命。

**瞽者善听，聋者善视。绝利一源，用师十倍；三反昼夜，用师万倍。**

眼瞎的人反而特别善于倾听，耳聋的人却往往目光锐利。这意味着：当某种感官受限，其他感知反而更加敏锐，这是“用拙为巧”的智慧。截断多余的欲望，专注于一个源头，就能使军力增效十倍；把这种专注持续到日夜多次循环，力量可提升到万倍。

[心生于物，死于物，机在目。](../摘录/心生于物，死于物，机在目。.md)

**恩生于害，害生于恩。愚人以天地文理圣，我以时物文理哲。**

恩惠往往源于祸患，而祸患也常常从恩惠中滋生。愚人靠天地表面之“文理”来理解圣人之道，而我则依据时机与事物的本质之理来领悟哲理。

# 未整理

中篇：讲“盗”的法则——怎么从规律中获取能量
下篇：讲“术”的方法——具体怎么干 

【中篇】
讲一个“盗”字，核心一句话：天地、万物、人，三者互相盗。 

“天地，万物之盗；万物，人之盗；人，万物之盗。三盗既宜，三才既安。” 
“盗”不是偷，是摄取、利用、转化。 

天地盗万物：老天下雨滋润草木，但草木死后又归于尘土。天地在万物身上“吸取”能量。
万物盗人：你吃粮食，粮食也在消耗你的身体。你养了一条狗，狗也消耗你的时间和金钱。
人盗万物：你吃牛羊、砍木材盖房子，这是你从万物身上获取能量。 

关键在“三盗既宜”——三者平衡了，才安。 

用一个比喻： 你工作盗取公司的钱，公司盗取你的劳动力，市场盗取所有公司的价值换交易。
谁都不能“盗”得太过。你996把自己干死了，那叫“盗”过了，三才不安了。 

“五贼” 那个让你痛苦的，恰恰是你的入处 
你贪的那个东西，就是“贼”它在你身上偷能量。但同时，你看见“贼”的那只眼睛，就是破贼的刀。你抽烟，你知道“火生于木”，你看见这个“贼”的时候，就已经在破它了。 
“三盗既宜”你和世界的关系是互相“偷”，平衡就好 
你不用当圣人。你“偷”众生的（从他们身上获得滋养、经验、甚至名利），众生也“偷”你的（你给他们法布施）。别偷得太狠，也别一点不偷（那是自绝于世界）。平衡，就是道。 

中篇还讲：“食其时，百骸理；动其机，万化安。” 
翻译：在正确的时间吃，身体就顺了；在正确的时机动，一切就安了。 
“时”和“机”是全书的关键词。不是什么时候都能干，是在那个“窗口期”干。 

中篇最后说了一句很重的话：“君子得之固躬，小人得之轻命。” 
翻译：这个东西（指掌握规律的方法），君子拿去能保全自己、成就事业；小人拿去会玩命、找死。 

刀没有善恶，看你用刀的人是谁。你拿刀去做手术救人，你是医生；你拿刀去砍人，你是罪犯。

【下篇】
下篇一开头就给了个经典比喻：“瞽者善听，聋者善视。绝利一源，用师十倍。” 
翻译：瞎子耳朵灵，聋子眼睛尖。切断一个干扰源，你在这方面的能力就增强十倍。 

用一个比喻： 你工作时手机放旁边，一会儿响一下，你一天效率很低。你把手机扔到另一个房间，专注力立刻翻倍。这就是“绝利一源”砍掉那个分散你的东西。 

它接着又说：“心生于物，死于物，机在目。” 
翻译：人心因为外物而生（欲望），也因为外物而死（沉溺），那个开关在哪里？在眼睛。 
你看了一眼跑车，心里就痒痒了。你多看了两眼美女，魂就被勾走了。眼睛是心的大门。所以想守住心，先管住眼。 

“天之无恩，而大恩生。迅雷烈风，莫不蠢然。” 
翻译：天不刻意给谁恩惠，但大恩惠自然就产生了。一阵雷一阵风，万物就蠢蠢欲动地生长了。 
利他不求回报，但那个喜乐比禅定还扎实。这就是“无恩而大恩生”不刻意追，它自己就来了。 

“至乐性余，至静性廉。” 
翻译：真正的快乐，人的性情是宽裕的（有余）；真正的静，人的性情是清廉的（不贪）。 

禽之制在气。 
翻译：鸟能飞（禽），靠的是“气”——那个内在的能量和节奏。你做事能不能成，也靠“气”。士气、底气、心气，没了气，啥都干不成。这就是我为什么一直说一定要保存“心力”的原因。 一个人能成事不在于聪明，而在于“心力”，一个人心力足了，他就能在一个行业里不疲倦的深耕，便能把更好的东西回馈给外界，换取资粮。 
而一但做了过度消耗心力的事，第二天一定是疲劳的，所以在我眼里，从世间缝隙中挤出来的时间去聚会，去旅游，这不是放松，而是扼杀“心力”
拐过头还要顶着内心的不愿和疲劳继续工作，不仅完全忘记游玩时的快乐，久而久之这种“不愿”就会无形之中使人癫狂。 

“生者死之根，死者生之根。” 
翻译：生是死的根，死是生的根。它们是互相转化的。 
秋天枯了，春天才发。你“死”了那个旧我，“新我”才生出来。

“恩生于害，害生于恩。” 
翻译：恩惠从伤害里生出来，伤害从恩惠里生出来。 
一个人要是很惨，你帮助他，他会觉得你很好，就生出恩惠了。但如果他过的很好，可能就不会在意你的帮助

“机在目”管住眼睛，就管住了一半的心“机心起，道心灭”。 
过来人常说“了了灵知不立一物”，眼睛就是在那个“立物”的入口。看到好看的，想不想多看一眼？看到不顺眼的，想不想瞪他一眼？那个“想”一动，“机”就动了。 
“绝利一源，用师十倍”专注才是破执的利器 
修《心中心》法坐两小时，就是“绝利一源”，把耳朵、嘴巴、身体都“绝”了，只在咒上。效果是平时的十倍甚至万倍。
你利他时的那种“忘我”状态，也是“绝利一源”你把“我”的那个“利”绝了，专注在对方身上，便能自然升起喜乐。
