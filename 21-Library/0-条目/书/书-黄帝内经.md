《黄帝内经》分《灵枢》《素问》两部分，是中国最早的医学典籍，其基本素材来源于中国古人对生命现象的长期观察、大量的临床实践以及简单的解剖学知识。

《黄帝内经》奠定了人体生理、病理、诊断以及治疗的认识基础，是中国影响极大的一部医学著作，被称为医之始祖。

《黄帝内经》在黄老道家理论上建立了中医学上的“阴阳五行学说”、“脉象学说”、“藏象学说”、“经络学说”、“病因学说”、“病机学说”、“病症”、“诊法”、“论治”及“养生学”、“运气学”等学说。 

# 《素问》
## 2 · 四气调神大论
春三月，此谓发陈。天地俱生，万物以荣，夜卧早起，广步于庭，被发缓形，以使志生，生而勿杀，予而勿夺，赏而勿罚，此春气之应，养生之道也；逆之则伤肝，夏为寒变，奉长者少。

```
春季的三个月（农历正月、二月、三月），这个季节叫做"发陈"。天地之间阳气一同生发，万物因此而欣欣向荣。人们应当稍晚入睡、早早起床，在庭院中从容地大步散步，披散开头发，舒缓放松身体，以便使精神情志随着春气一同生发畅达。在情志和行为上，要做到促进生发而不要扼杀，对待万物要给予而不要剥夺，奖赏而不要惩罚。这就是与春季生发之气相适应的、调养"生"机的法则。如果违背了春季的养生法则，就会损伤肝脏；到了夏天就会发生寒性病变（如腹泻、畏寒等），这是因为春天供给夏天"长"气的基础太少了。

发：生发、萌动。意为春天阳气升发。
陈：陈旧、蓄积。将冬天蓄积的旧物推陈出新，万物萌生。
夏为寒变：春天阳气生发不足，到了夏天阳气当旺不旺，反而出现寒性病变。这是"母病及子"（春木生夏火，春伤则夏虚）的传变规律。
```

夏三月，此谓蕃秀。天地气交，万物华实，夜卧早起，无厌于日，使志无怒，使华英成秀，使气得泄，若所爱在外，此夏气之应，养长之道也；逆之则伤心，秋为痎疟，奉收者少，冬至重病。

```
夏季的三个月（农历四月、五月、六月），这个季节叫做"蕃秀"。天之阳气下降，地之阴气上升，天地之气交合融通，万物开花结实。人们应当晚些入睡、早早起床，不要厌恶夏日的漫长日照。使情志保持平和而不发怒，让精神像花朵一样绽放秀美，让体内阳气能够顺畅地向外宣散发泄，就好像心中所喜爱的事物都在外面一样（心情外向、开朗、热情）。这就是与夏季蕃秀之气相适应的、调养"长"机的法则。如果违背了夏季的养生法则，就会损伤心脏；到了秋天就容易患疟疾类疾病，这是因为供给秋天"收"气的基础不足；到了冬天病情会更加严重。

蕃秀：万物繁茂到了极点，开花结果，一派葱郁华美之象。概括了夏季"长"的特征。
无厌于日：夏天阳光充沛，不要躲避、讨厌日照。适当接受阳光有助于阳气宣通。
使气得泄：夏季阳气旺盛于外，腠理开泄，汗出散热，是正常生理。不可过度贪凉遏阻阳气外泄。
```

秋三月，此谓容平。天气以急，地气以明，早卧早起，与鸡俱兴，使志安宁，以缓秋刑，收敛神气，使秋气平，无外其志，使肺气清，此秋气之应，养收之道也；逆之则伤肺，冬为飧泄，奉藏者少。

```
秋季的三个月（农历七月、八月、九月），这个季节叫做"容平"。秋风劲急，天高气爽，地气清肃明净。人们应当早睡早起，像鸡一样随天亮而起身。使情志保持安宁平静，以缓和秋天肃杀之气对人体的伤害；收敛精神和元气，使身心与秋气的平定相适应；不要让情志向外驰散，使肺气保持清肃。这就是与秋季容平之气相适应的、调养"收"机的法则。如果违背了秋季的养生法则，就会损伤肺脏；到了冬天就会发生完谷不化的泄泻，这是因为供给冬天"藏"气的基础不足。

容平：万物经过春夏的生长，到秋天已经成熟定型，呈现出从容平定的状态。概括了秋季"收"的特征。
冬为飧（sūn）泄：飧泄，大便中夹杂未消化的食物残渣（完谷不化），属脾肾阳虚之证。秋天收敛不足，阳气未能内藏，到冬天肾阳虚衰，不能温煦脾土，故泄泻。
```

冬三月，此谓闭藏。水冰地坼，无扰乎阳，早卧晚起，必待日光，使志若伏若匿，若有私意，若已有得，去寒就温，无泄皮肤，使气亟夺。此冬气之应，养藏之道也；逆之则伤肾，春为痿厥，奉生者少。

```
冬季的三个月（农历十月、十一月、十二月），这个季节叫做"闭藏"。水结成冰，大地冻裂，此时不要扰动体内的阳气。人们应当早早入睡、晚晚起床，一定要等到太阳出来之后再起身活动。使情志如同潜伏隐匿一般深沉内敛，好像心中怀有私密的心思不愿外露，又好像已经有所收获而心满意足、不再外求。远离寒冷、靠近温暖，不要让皮肤腠理开泄出汗，以免阳气被频频耗夺。这就是与冬季闭藏之气相适应的、调养"藏"机的法则。如果违背了冬季的养生法则，就会损伤肾脏；到了春天就会发生肢体痿弱无力、四肢厥冷的病症，这是因为供给春天"生"气的基础不足。

闭藏：概括了冬季万物收藏蛰伏、阳气深潜的特征。
```

天气，清净光明者也，藏德不止，故不下也。

```
天的气象，本来是清净光明的，它蕴藏其德性而不止息，所以天体高悬而不坠落。

真正的"明"在于内藏，而非外露。与上文冬季"闭藏"之理暗合。
```

天明则日月不明，邪害空窍。

```
如果天不能藏德而过于显露其明（阳气外泄太过），那么日月的光辉反而不能正常照耀，邪气就会乘虚侵害人体的孔窍。

阳气不藏则邪气入侵。

邪害空窍：空窍，人体的九窍（眼、耳、鼻、口、前后二阴）。天气失常，则人体正气不固，邪气趁虚而入。
```

阳气者闭塞，地气者冒明，云雾不精，则上应白露不下。

```
如果阳气闭塞不通，地气就会昏蒙遮蔽光明，云雾浑浊不清，那么天上相应的甘露就不会降下。
```

交通不表，万物命故不施，不施则名木多死。

```
天地之气不能交通感应、彰显于外，万物的生命就不能正常生长发育，不能生长发育则高大的树木也会大量枯死。
```

恶气不发，风雨不节，白露不下，则菀槁不荣。

```
污浊的恶气不能发散清除，风雨失去节度，甘露不能降下，那么草木就会郁积枯槁而不能繁荣。
```

贼风数至，暴雨数起，天地四时不相保，与道相失，则未央绝灭。

```
贼风频繁袭来，暴雨屡屡骤起，天地四时的正常秩序不能相互保持，与自然之道相背离，那么万物还未到终其天年就会中途灭绝。
```

唯圣人从之，故身无苛病，万物不失，生气不竭。

```
只有圣人能够顺应自然之道，所以自身没有严重的疾病，万物的生机不会丧失，生命的元气不会枯竭。
```

逆春气则少阳不生，肝气内变。

```
违背春季之气，则少阳之气不能生发，肝气就会在内部发生病变。
```

逆夏气则太阳不长，心气内洞。

```
违背夏季之气，则太阳之气不能盛长，心气就会在内部空虚不足。
```

逆秋气则太阴不收，肺气焦满。

```
违背秋季之气，则太阴之气不能收敛，肺气就会焦燥壅满。
```

逆冬气则少阴不藏，肾气独沉。

```
违背冬季之气，则少阴之气不能封藏，肾气就会独自沉衰于下。
```

夫四时阴阳者，万物之根本也。所以圣人春夏养阳，秋冬养阴，以从其根；故与万物沉浮于生长之门。逆其根则伐其本，坏其真矣。

```
四季的阴阳变化，是万物生长化收藏的根本。所以圣人在春夏季节注重养护阳气，在秋冬季节注重养护阴气，以顺应生命的根本；因此能够与万物一起，在生长收藏的门户中随顺浮沉。如果违背了这个根本，就是砍伐了生命的根基，毁坏了人体的真气。
```

故阴阳四时者，万物之终始也；死生之本也；逆之则灾害生，从之则苛疾不起，是谓得道。

```
因此，阴阳四时的变化，是万物从始至终的规律；是决定生死的根本；违背它就会灾害丛生，顺应它则重病不会发生，这就叫做"得道"。
```

道者，圣人行之，愚者佩之。从阴阳则生，逆之则死；从之则治，逆之则乱。反顺为逆，是谓内格。

```
这个"道"，圣人切实地去践行它，愚昧的人只是把它挂在嘴边（或违背它）。顺应阴阳就能生存，违背阴阳就会死亡；顺应它就身体安和，违背它就气血紊乱。把顺当作逆、颠倒行事，这就叫做"内格"。
```

是故圣人不治已病，治未病；不治已乱，治未乱，此之谓也。夫病已成而后药之，乱已成而后治之，譬犹渴而穿井，斗而铸锥，不亦晚乎？

```
因此，圣明的医者不是等到疾病已经形成了才去治疗，而是在疾病尚未发生时就进行预防；不是等到祸乱已经形成了才去治理，而是在祸乱尚未萌发时就加以防范。说的就是这个道理。
```

## 126 · 外揣
黄帝曰：余闻九针九篇，余亲受其调，颇得其意。夫九针者，始于一而终于九，然未得其要道也。夫九针者，小之则无内，大之则无外，深不可为下，高不可为盖，恍惚无窍，流溢无极，余知其合于天道人事四时之变也，然余愿杂之毫毛，浑束为一，可乎？

```
我曾听闻关于九针的九篇论述，并且亲自接受了其中的调理之法，已经大致领会了其中的要旨。

九针之法，从第一针开始到第九针结束，（我虽然学了这些），但还没有掌握其中最根本的核心道理。

九针的道理，往细微处说，精细到没有更小的内部可言；往广大处说，宏博到没有更大的外部可言；往深处说，深到不能再往下探；往高处说，高到不能再向上覆盖；它玄妙恍惚，找不到穷尽的入口；它流布扩散，没有止境和边界。我知道九针的道理是与天道运行、人事变化、四季更替的规律相吻合的。然而我希望能把这些纷繁复杂、细如毫毛的众多道理，浑然归总、统合为一个根本的原则，可以做到吗？
```

岐伯曰：明乎哉问也！非独针道焉，夫治国亦然。

```
这个问题问得太高明了！不仅仅是针灸之道如此，治理国家也是同样的道理。
```

黄帝曰：余愿闻针道，非国事也。

```
我想听的是针灸的道理，不是治国的事务。
```

岐伯曰：夫治国者，夫惟道焉，非道，何可小大深浅，杂合而为一乎？

```
治理国家这件事，关键就在于一个"道"字。如果不是掌握了这个根本的"道"，又怎么可能把大小、深浅等千差万别的事物综合统一为一个整体呢？
```

黄帝曰：愿卒闻之。

```
希望您能详尽地把这个"道"讲给我听。
```

岐伯曰：日与月焉，水与镜焉，鼓与响焉。夫日月之明，不失其影；水镜之察，不失其形；鼓响之应，不后其声。动摇则应和，尽得其情。

```
这个"道"就好比太阳月亮与影子的关系，水面镜子与映像的关系，击鼓与声响的关系。

日月的光明照耀万物，绝不会丢失任何物体的影子。平静的水面和明亮的镜子照映万物，绝不会丢失任何物体的形状。鼓槌击鼓发出的声响回应，绝不会落后于击打的声音。

一旦有所触动，就会立即产生应和，（通过这些应和关系）就能完全掌握事物的真实情况。
```

黄帝曰：窘乎哉! [昭昭之明不可蔽，其不可蔽，不失阴阳也](../../../999-Insights/未关联/昭昭之明不可蔽，其不可蔽，不失阴阳也.md)。合而察之，切而验之，见而得之，若清水明镜之不失其形也。五音不彰，五色不明，五脏波荡，若是则内外相袭，若鼓之应桴，响之应声，影之似形。故远者司外揣内，近者司内揣外，是谓阴阳之极，天地之盖。请藏之灵兰之室，弗敢使泄也。

```
这真是太深奥微妙了！显而易见、光明昭著的道理是无法被掩盖的；它之所以不能被遮蔽，是因为它完全符合阴阳变化的客观规律。

把各种诊察方法综合起来分析，通过切按脉象和部位来检验，通过望诊观察气色来体察，就能像清澈的静水和明亮的镜子照物一样，丝毫不差地反映出病情的真相。

如果一个人的五音（言语声音）不再洪亮谐调，五色（面部气色）不再润泽明朗，就说明体内的五脏已经发生了动荡不安的病变。像这样，体内脏腑与体表外相是相互呼应、内外相通的，就像鼓槌敲击鼓面必然发出声响、回声必然呼应原声、影子必然随附形体一样分毫不差。

因此，对于深藏在内、看不见的五脏病变，可以通过观察体表的外部征象来推测（司外揣内）；对于已经了解的体内病变，也可以推断它在体表会产生怎样的表现（司内揣外）。这就是阴阳学说发挥到极致的道理，涵盖了天地万物变化的规律。

请允许我将这些至理名言珍藏在灵兰之室（国家藏书的秘阁），绝不敢轻易泄露！
```

## 161 · 大惑论
黄帝问于岐伯曰：余尝上于清冷之台，中阶而顾，匍匐而前，则惑。余私异之，窃内怪之，独瞑独视，安心定气，久而不解。独博独眩，披发长跪，俛而视之，后久之不已也。卒然自上，何气使然？

岐伯对曰：五脏六腑之精气，皆上注于目而为之睛。睛之窠为眼，骨之精为瞳子，筋之精为黑眼，血之精为络，其窠气之精为白眼，肌肉之精为约束，裹撷筋骨血气之精而与脉并为系。上属于脑，后出于项中。故邪中于项，因逢其身之虚，其入深，则随眼系以入于脑。入于脑则脑转，脑转则引目系急，目系急则目眩以转矣。邪其睛，其睛所中，不相比也，则精散。精散则视歧，视歧见两物。目者，五脏六腑之精也，营卫魂魄之所常营也，神气之所生也。故神劳则魂魄散，志意乱。是故瞳子黑眼法于阴，白眼赤脉法于阳也，故阴阳合传而睛明也。目者，心之使也。心者，神之舍也，故神分精乱而不转，卒然见非常之处，精神魂魄，散不相得，故曰：惑也。

黄帝曰：余疑其然。余每之东苑，未曾不惑，去之则复，余唯独为东苑劳神乎？何其异也！

岐伯曰：不然也。心有所喜，神有所恶，卒然相惑，则精气乱，视误，故惑，神移乃复。是故，间者为迷，甚者为惑。

黄帝曰：人之善忘者，何气使然？

岐伯曰：上气不足，下气有余，肠胃实而心肺虚。虚则营卫留于下，久之不以时上，故善忘也。

黄帝曰：人之善饥而不嗜食者，何气使然？

岐伯曰：精气并于脾，热气留于胃，胃热则消谷，谷消故善饥。胃气逆上，则胃脘寒，故不嗜食也。

黄帝曰：病而不得卧者，何气使然？

岐伯曰：卫气不得入于阴，常留于阳。留于阳则阳气满，阳气满则阳蹻盛，不得入于阴则阴气虚，故目不得瞑矣。

黄帝曰：病目而不得视者，何气使然？

岐伯曰：卫气留于阴，不得行于阳。留于阴则阴气盛，阴气盛则阴蹻满，不得入于阳则阳气虚，故目闭也。

黄帝曰：人之多卧者，何气使然？

岐伯曰：此人肠胃大而皮肤湿，而分肉不解焉。肠胃大则卫气留久；皮肤湿则分肉不解，其行迟。夫卫气者，昼日常行于阳，夜行于阴，故阳气尽则卧，阴气尽则寤。故肠胃大，则卫气行留久；皮肤湿，分肉不解，则行迟。留于阴也久，其气不清，则欲瞑，故多卧矣。其肠胃小，皮肤滑以缓，分肉解利，卫气之留于阳也久，故少瞑焉。

黄帝曰：其非常经也，卒然多卧者，何气使然？

岐伯曰：邪气留于上焦，上焦闭而不通，已食若饮汤，卫气留久于阴而不行，故卒然多卧焉。

黄帝曰：善。治此诸邪，奈何？

岐伯曰：先其脏腑，诛其小过，后调其气，盛者泻之，虚者补之，必先明知其形志之苦乐，定乃取之。
