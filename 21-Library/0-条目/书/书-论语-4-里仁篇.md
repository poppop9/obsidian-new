# 正文
## 4.1
**子曰：“里仁为美。择不处仁，焉得知？”**

孔子说：“住的地方，要有仁德之风这才好。选择住处，没有仁德，怎么能是聪明呢？”

```
里： 居住
处： chǔ，居住
知： 究竟孔子是单纯地指“择居”而言呢，还是泛指，“择邻”、“择业”、“择友”等等都包括在内呢？我们不敢肯定
```

## 4.2 ⭐️
**子曰：“不仁者不可以久处约，不可以长处乐。仁者安仁，知者利仁。”**

孔子说：“不仁的人不可以长久地居于穷困中，也不可以长久地居于安乐中。仁德的人，实行仁德便心安，不实行仁德心便不安；聪明人认识到仁德对他有巨大的利益，所以会去实行仁德。”

```
- 缺乏内在仁德的人，情绪和行为是随环境剧烈波动的，环境越极端，他们表现得越糟糕
- 有仁德的人行善不是为了名声，也不是为了回报，纯粹是因为不这样做心不安，无论贫穷还是富有，他的内心是恒定的
- 聪明人明白“仁”是长远发展的最优解。他知道做个好人、讲信用、有仁德能让他获得更好的社会关系、更少的麻烦和更长远的利益
```

## 4.3
**子曰：“唯仁者能好人，能恶人。”**

孔子说：“只有仁人才能够喜爱某人，厌恶某人。”

## 4.4
**子曰：“苟志于仁矣，无恶也。”**

孔子说：“假如立定志向实行仁德，总没有坏处。”

## 4.5 ⭐️
**子曰：“富与贵，是人之所欲也；不以其道得之，不处也。贫与贱，是人之所恶也；不以其道得之，不去也。君子去仁，恶乎成名？君子无终食之间违仁，造次必于是，颠沛必于是。”**

孔子说：“发大财，做大官，这是人人所盼望的；不用正当的方法去得到它，君子不接受。穷困和下贱，这是人人所厌恶的；不用正当的方法去抛掉它，君子不摆脱。君子抛弃了仁德，怎样去成就他的声名呢？君子没有吃完一餐饭的时间离开仁德，就是在仓卒匆忙的时候一定和仁德同在，就是在颠沛流离的时候一定和仁德同在。”

## 4.6
**子曰：“我未见好仁者，恶不仁者。好仁者，无以尚之；恶不仁者，其为仁矣，不使不仁者加乎其身。有能一日用其力于仁矣乎？我未见力不足者。盖有之矣，我未之见也。”**

孔子说：“我不曾见到过爱好仁德的人和厌恶不仁德的人。爱好仁德的人，那是再好也没有的了；厌恶不仁德的人，他行仁德只是不使不仁德的东西加在自己身上。有谁能在某一天使用他的力量于仁德呢？我没见过力量不够的。大概这样人还是有的，我不曾见到罢了。”

```
孔子把追求道德的人分为两个等级，但孔子表示这两种人都很少看见
- 高级版（好仁者）—— 发自内心地热爱仁，行善就像吃美食、看美色一样，是一种本能的享受。这种境界高不可攀
- 初级版（恶不仁者）—— 虽然还没到“热爱”的程度，但他非常讨厌肮脏、卑鄙的事

孔子还认为实行仁，不要拿能力不足当借口，如果你真的愿意拿出哪怕一整天的时间，全心全意地去实践道德，还没见过谁是力气不够用的

尚： 超过
盖： 大概
```

## 4.7
**子曰：“人之过也，各于其党。观过，斯知仁矣。”**

孔子说：“人是各种各样的，人的错误也是各种各样的。什么样的错误就是由什么样的人犯的。仔细考察某人所犯的错误，就可以知道他是什么样式的人了。”

```
通常我们了解一个人是通过他的优点，但孔子认为，缺点和错误往往比优点更能暴露一个人的本质
```

## 4.8 ⭐️
**子曰：“朝闻道，夕死可矣。”**

孔子说：“早晨得知真理，要我当晚死去，都可以。”

## 4.9
**子曰：“士志于道，而耻恶衣恶食者，未足与议也”**

孔子说：“读书人有志于真理，但又以自己吃粗粮穿破衣为耻辱，这种人，不值得同他商议了”

```
真正拥有大智慧的人，内心是极其充实的，他们对外在的物质条件会有极强的免疫力。那些因为物质条件差就觉得丢人的人，说明他们骨子里评价人的标准依然是“钱”和“物质”，而不是“道德”和“思想”
```

## 4.10 ⭐️
**子曰：“君子之于天下也，无适也，无莫也，义之与比”**

孔子说：“君子对于天下的事情，没规定要怎样干，也没规定不要怎样干，只要怎样干合理恰当，便怎样干”

```
有道德不是死守规矩，孔子提倡的是外圆内方、通权达变。不被死板的规矩、偏见、执念所绑架，只要大方向符合道德和正义，手段和方法可以随时调整

适： dì，盲目地偏向某一面
莫： mò，盲目地排斥
比： bì，挨着，靠拢，为邻
```

## 4.11
**子曰：“君子怀德，小人怀土；君子怀刑，小人怀惠”**

孔子说：“君子怀念道德，小人怀念乡土；君子关心法度，小人关心恩惠”

## 4.12 ⭐️
**子曰：“放于利而行，多怨”**

孔子说：“依据个人利益而行动，会招致很多的怨恨”

```
如果你在工作、生活中，每一个决定都在算计怎么让自己利益最大化，那么必然意味着你在剥夺或损害他人的利益
```

## 4.13
**子曰：“能以礼让为国乎？何有？不能以礼让为国，如礼何？”**

孔子说：“能够用礼让来治理国家吗？这有什么困难呢？如果不能用礼让来治理国家，又怎样来对待礼仪呢？”

```
如果内心没有谦让之心，只是机械地执行礼仪（比如穿华丽的礼服、磕头、祭祀），那么这些礼仪就变成了虚伪的形式主义。如果你做不到“让”，你的“礼”就是空的
```

## 4.14 ⭐️
**子曰：“不患无位，患所以立。不患莫己知，求为可知也。”**

孔子说：“不发愁没有职位，只发愁没有任职的本领；不怕没有人知道自己，去追求足以使别人知道自己的本领好了”

## 4.15
**子曰：“参乎！吾道一以贯之”。曾子曰：“唯”。子出，门人问曰：“何谓也？”。曾子曰：“夫子之道，忠恕而已矣。”**

孔子说：“参呀！我的学说贯穿着一个基本观念”。曾子说：“是”。孔子走出去以后，别的学生便问曾子道：“这是什么意思”。曾子道：“他老人家的学说，只是忠和恕罢了”

```
忠和恕的概念，上述核心字词解释有说明
```

## 4.16 ⭐️
**子曰：“君子喻于义，小人喻于利”**

孔子说：“君子懂得的是义，小人懂得的是利”

```
这句话并不是说君子不需要钱，小人每天都在做坏事。它的核心在于讲君子与小人的决策逻辑
- 君子的逻辑（义）—— 当面临一件事时，君子首先想的是这件事应不应该做、这样做是否符合道德和良心，即使有很大的利益诱惑，如果这件事不符合“义”，君子也会拒绝
- 小人的逻辑（利）—— 当面临一件事时，小人首先想的是这件事对我有没有好处、我能赚多少钱、我能不能占到便宜，哪怕这件事违背了道德，只要对自己有利，小人就会去做

喻： yù
```

## 4.17 ⭐️
**子曰：“见贤思齐焉，见不贤而内自省也”**

孔子说：“看见贤人，便应该想向他看齐；看见不贤的人，便应该自己反省，有没有同他类似的毛病”

## 4.18 ⭐️
**子曰：“事父母几谏，见志不从，又敬不违，劳而不怨”**

孔子说：“侍奉父母，如果他们有不对的地方，得轻微婉转地劝止，看到自己的心意没有被听从，仍然恭敬地不触犯他们，虽然忧愁，但不怨恨”

```
看到父母犯错而不劝，陷父母于不义，那是不孝。所以你必须要指出父母的错误。但要注重沟通方式，父母毕竟是长辈，直接数落、批评，会伤害他们的自尊心，导致他们为了面子而更加固执。所以要“委婉”地劝

几： jī，轻微，婉转
违： 触忤，冒犯
劳： 忧愁
```

## 4.19
**子曰：“父母在，不远游，游必有方”**

孔子说：“父母在世，不出远门，如果要出远门，必须有一定的去处”

## 4.21 ⭐️
**子曰：“父母之年，不可不知也。一则以喜，一则以惧”**

孔子说：“父母的年纪不能不时时记在心里：一方面因其高寿而喜欢，另一方面又因其寿高而有所恐惧”

```
- 为什么喜： 父母又长了一岁，说明他们身体尚健，依然陪伴在我们身边，我们还有机会报答养育之恩，这是做子女最大的福气
- 为什么惧： 父母每增加一岁，就意味着他们离衰老和死亡又近了一步，看着父母日益苍老的容颜、逐渐弯下的脊背，子女会感到一种时间的紧迫感
```

## 4.22 ⭐️
**子曰：“古者言之不出，耻躬之不逮也”**

孔子说：“古时候言语不轻易出口，就是怕自己的行动赶不上”

## 4.23 ⭐️
**子曰：“以约失之者鲜矣”**

孔子说：“因为对自己节制、约束而犯过失的，这种事情总不会多”

```
一个有原则、守规矩的人，虽然看起来不如那些投机取巧的人灵活，也不如他们风光，但他走得稳。在孔子看来，稳健的克制比冒险的放纵更安全
```

## 4.24
**子曰：“君子欲讷于言而敏于行”**

孔子说：“君子言语要谨慎迟钝，工作要勤劳敏捷”

```
学而篇也讲到了，不再赘述

讷： nà，语言迟钝
```

## 4.25 ⭐️
**子曰：“德不孤，必有邻”**

孔子说：“有道德的人不会孤单，一定会有志同道合的人来和他做伙伴”

## 4.26 ⭐️
**子游曰：“事君数，斯辱矣；朋友数，斯疏矣”**

子游说：“对待君主过于烦琐，就会招致侮辱；对待朋友过于烦琐，就会反被疏远”

```
这句话的核心在于探讨人际关系的边界感和分寸感，子游其实是在告诫我们，无论是职场还是交友，都要把握好度
- 职场： 看到君主有错就拼命劝告，哪怕你是出于好意，但如果不分场合、不看脸色，就会显得你比君主还聪明，或者显得君主很昏庸，这会触碰到上位者的自尊心
- 交友： 过度劝解、介入对方私生活

数： shuò，烦琐
```
