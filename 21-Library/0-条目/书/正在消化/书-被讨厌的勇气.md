# 📚 自我认知
**维持现状 vs. 改变**
- 你之所以不幸，不是因为你缺乏能力，也不是因为过去太惨，而是因为你缺乏获得幸福的勇气。
- 抱怨不幸虽然痛苦，但是比较轻松；改变的成本很高，你要面对未知的恐惧，和承担失败的风险。

**生活方式**
- 从狭义上来讲，生活方式可以理解为性格。阿德勒认为大约是在 10 岁左右的时候，自己无意识地选择了自己的性格，也就是生活方式。
- 从广义上来说，生活方式是世界观或人生观。生活方式 = 如何看世界 (世界观) + 如何看自己 (自我概念) + 赋予什么意义 (价值观)。
- 虽然外部因素会对你的人生产生很大的影响，但是任何经历本身并不是成功或者失败的原因，你的人生还是由你自己选择的，是你自己选择如何生活。

# 📚 人际关系
**自卑感**
- 自卑感本身不是坏事，它是推动进步的动力。
- 正确的自卑感不是来自与别人的比较，而是来自与理想的自己比较。
- 如果有人骄傲自大，那一定是因为他有强烈的自卑感。

**竞争观 vs. 伙伴观**：如果站在竞争的角度考虑人际关系，总是把他人的幸福看作我的失败，无法真心祝福他人，就算你有社会性的成功，你也不会幸福。

**认可欲**：根本没必要被别人认可，也不要去寻求认可，甚至可能被他人讨厌都无所谓，我们都不是为了满足别人的期待而活着。

## 📖 课题分离
**为什么要课题分离**
- 一切人际关系矛盾都起因于课题地互相干涉，课题分离是建立横向关系的入口和手段。
- 如果想要与人和谐相处，就必须把对方当成平等的个体，摒弃纵向的上下级思维。

**如何分辨是谁的课题**：只考虑某种选择所带来的结果最终由谁承担，由谁承担，就是谁的课题。

**干涉课题的后果**：倘若无视本人的意愿而强迫其改变，那结果只会是日后产生更加强烈的反作用，能够改变自己的只有自己。

**案例**：如果眼前有一个非常苦恼的人，我们需要做一些不是干涉的援助，我们要在理解了这个课题是别人的基础上再去考虑要援助的事情，不去居高临下地命令，而是努力地帮助他本人建立自信，以及提高其独立应对课题的能力（非暴力沟通中的同理倾听就是在帮助别人理清自己的课题）

> 关于自己的人生，你能够做的就是选择自己认为最好的道路。别人如何评价，那是别人的课题，你无法左右。

## 📖 共同体感觉
```
共同体感觉
├── 归属感
├── 他者关怀
├── 合作意识
├── 贡献意识
└── 把他人视为伙伴而非敌人
```

**找到共同体感觉的路径**：主动付出 → 感觉自己对他人有用 → 体会到自我价值 → 获得生活的勇气 → 找到在共同体中的位置。

**归属感**
- 误区：认为只要加入一个组织就有归属感、认为只要别人接纳我、爱我，就有归属感。
- 正确定义：归属感来自于我对共同体有益的主观感觉，它是通过主动去爱赢回来的（我能帮别人做什么、我能为团队贡献什么），当你开始付出，当你感觉到自己对他人有用时，你自然就找到了自己在共同体中的位置。共同体感觉是人际关系的最终目的。

**自我中心主义**：认为自己是世界的中心，觉得别人的好理所当然，永远在等待别人来服务你，而不是主动去建立关系，一旦别人没有满足期待，你就愤怒、失望。

## 📖 实现共同体感觉的三大支柱
**自我接纳**
- 自我接纳不是自我肯定。
- 反面案例：明明自己不行，还骗自己说我能行。
- 案例：做不到，就诚实地接受这个做不到的自己。

**他者信赖**
- 他者信赖是不附加任何条件的无条件相信。
- 他者信赖是搞好人际关系和构建横向关系的一种手段，如果你并不想与那个人搞好关系的话，那你可以选择不信赖。
- 与信用的区别：信用有附加条件，例如从银行贷款，就必须提供某些抵押。

**他者贡献**
- 他者贡献是为了能够体会到自身的价值，对伙伴给予影响、作出贡献。
- 他者贡献不是自我牺牲（为了他人牺牲自己的人生，这是过度适应社会的表现）。

## 📖 人生观
**正确的人生观**：不要把人生理解为一条线，而要理解成点的连续（也就是说人生是连续的刹那），每一个瞬间既是终点，也是起点。

**认知误区**：大人们总是想要强迫年轻人过线一样的人生（在他们看来，上好大学、进好企业、拥有稳定的家庭，这样的轨道才是幸福的人生），但是人生充满了偶然和突变，计划式的人生不是有没有必要的问题，而是根本不可能。

**行动指南**：只关注当下的舞步，而不是关注跳到了哪里，做好现在能做的事。

# 你的不幸是自己选择的
佛洛依德提出的原因论（心理创伤学说）认为过去所受的伤害是引起目前不幸的罪魁祸首。
而阿德勒提出的目的论（阿德勒心理学）认为决定现在的，不是过去的经历，而是我们自己赋予经历的主观意义。我们并非因为过去的经历而痛苦，事实上我们会从经历中发现符合自己目的的因素。

**案例**
- 与异性交谈时脸红，这并非过去的阴影所致，而是因为你心生恐惧，便制造出脸红这一症状作为逃避的借口，以此自我安慰：“我只是因为脸红才做不到，只要不脸红，我也能行。”
- 一个人过去受到过父母的打压，现在不敢出门。阿德勒心理学认为，并不是因为不安才无法走出去的，而是由于不想到外面去，想引起父母的注意，<sub></sub>所以才制造出不安的情绪。
- 如果你过去遭遇了父母变故，你现在过的很差，你就会说：“就是因为过去，我才会变成这个样子。”如果你现在过的很好，你会说：“就是因为我的过去，我才能更加坚韧，现在才能如此成功。”
- 愤怒只是达成目的的一种手段。人发脾气并不是受怒气支配而大发雷霆，而是为了通过大发雷霆来震慑对方，所以制造出来愤怒的感情，因为认为大发雷霆来解决问题比较省力。有一天母亲和女儿在大声争吵。正在这时候，电话铃响了起来。“喂喂？”慌忙拿起话筒的母亲的声音中依然带有一丝怒气。但是，打电话的人是女儿学校的班主任。意识到这一点后，母亲的语气马上变得彬彬有礼了。就这样，母亲用客客气气的语气交谈了大约 5 分钟之后挂了电话，接着又勃然变色，开始训斥女儿。

# 如何改变不幸
## 纠结过去，只会让你止步不前
发生什么事不重要，我们怎么看待这些事才重要。

人并不是住在客观的世界，而是住在自己营造的主观世界里。所以“如何看待”很重要。

如果一味地关注过去的原因，企图仅仅靠原因去解释事物，最终你会认为现在甚至未来全部都由过去的事情所决定，而且根本无法改变。

阿德勒心理学考虑的不是过去的“原因”，而是现在的“目的”。
