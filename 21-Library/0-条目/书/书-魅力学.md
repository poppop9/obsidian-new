# 四种常见的魅力风格
除以下四种风格外，还有其他魅力风格，只不过这四种是最实用的，你要根据不同的场合调整你的魅力风格。

## 专注型魅力
专注型魅力就是「临在感」+「尊重他人」，让对方喜欢他们自己，并觉得他们自己的意见很重要，不必让他人觉得你多聪明，只需让他们觉得自己聪明就行了。

```
马斯克、比尔盖茨、前 IBM 总裁基勒

管理顾问、服务领域、律师、会计师、财务顾问
```

1）适用边界
- 适合：商业场合、谈判、化解冲突、需要别人敞开心胸、分享信息时。
- 不适合：有必要展现权威、需要人们听从指示、不希望对方对你倾吐太多时。

2）阴阳平衡
- 需要一点亲和力 —— 没有亲和力会让人觉得咄咄逼人
- 需要一点影响力 —— 没有影响力会让人觉得你姿态很低，可能有求于他

## 仁慈型魅力
仁慈型魅力主要来自于「亲和力」，使对方感到备受欢迎、被全心全意的接纳与包容。

```
达赖喇嘛
```

1）适用边界
- 适合场合 —— 宣布坏消息、应付难以相处的人时
- 不适合场合 —— 有必要展现权威、不希望对方对你倾吐太多时

2）阴阳平衡：需要一点影响力，没有影响力会让人觉得你想要取悦他人。

## 远见型魅力
远见型魅力主要来自于「影响力」，能带给人们信念，让人感到热血沸腾。

```
乔布斯
```

1）适用边界：激励人心的场合、危机时刻。

2）阴阳平衡：需要一点亲和力，没有亲和力会让人非常讨厌。

Q 如何展现远见型魅力？
A 你必须向他人投射出对某个理想抱持坚不可摧的信心，并且必须涵盖某种程度的高贵情操与利他行为

Q 为什么有远见就魅力十足？
A 我们天生讨厌不确定感，在变化多端的世界，我们渴望有个明确的东西能握在手中。

## 权威型魅力
权威型魅力主要来自于「影响力」。

1）适用边界
- 适合：希望别人照你的指示做事时、危机时刻。
- 不适合：想要激发创造力（因为权威会抑制他人的批判性思考）、希望获得建设性回馈时。

2）阴阳平衡：需要一点亲和力，没有亲和力会让人非常讨厌。

# 魅力常见的阻碍
## 1）环境因素
环境因素引起的肢体不适，例如：

```
大热天穿着羊毛衣服

太阳直射了你的眼睛

低血糖

附近工地噪音的干扰
```

我们有两个解决办法：
1）提前预防，充分准备，避免环境因素的干扰。
2）做出解释，让对方知道你的不适是因为某个特定原因。

## 2）心理不适
内心怎么想，身体就会怎么表现，若是你的内在处于富含魅力的状态，那么不费吹灰之力就能做出正确的肢体语言。但如果心理不适（自我怀疑、焦虑、比较），那将会削弱我们的临在感、会产生焦虑、还会产生负面情绪、让我们的肢体语言不自然。

对于这种情况引起的肢体不适，我们只能通过改变内心，从而间接控制肢体语言，因为我们无暇顾及和改善所有的肢体语言。解决方案如下：

1）责任转移：当我们面对不确定时，其实最想要的是事情能顺利进行，每件事都有人负责，你可以进行以下练习
1. 舒服的坐着 / 躺下，放轻松，闭上眼睛
2. 做三次深呼吸：吸气时，想像自己将纯净的空气引导到头顶；呼气时，让这股气息快速窜流全身，洗净所有的忧虑与烦恼
3. 选择某个仁慈的神祇 ── 上帝、命运之神、宇宙
4. 想像把肩上扛着的忧虑卸下，转移到你选定的神祇肩上，它能够替你托管心中所有的烦恼
5. 观想自己肩上的所有重责全数卸下，现在的你不必再对任何事物的结果负责，每件事都已获得托管

2）将不适感去污名化：告诉自己“你不是世上唯一有这种内在不适的人，还有很多人和你一样正在经历你目前正在承受的痛苦”，把它想像成一群人在受煎熬，这个难熬的重担是大家在一起承担。

```
假设你刚失去了一个重要客户。不妨想想认识的人（某位精神导师、仰慕的人）当中是不是也经历过类似的挫折，想想他们是怎么熬过来的。当然，若是本人能亲口向你诉说他们的故事是最理想的。
```

3）改写事实，把事情往好的方面想，也就是假想法。

```
这次会议没成功，没关系，上帝会保佑我的，后面肯定有其他比这更好的机会在等着我。

如果你焦虑演讲，你可以幻想自己成功的场面越细节越好，最好把过程写下来。

你怨恨他人，但是又不得不与他相处，可以把他的道歉过程想象出来并写下来。

对方可能只是因为内心不舒服才会显现出这样的神情，与我无关。

若是碰到较严重的情况，你可以写下一段全新的事实。「书写」能让我们使用不同的大脑部位，比其他表达方式更能够撼动个人的信念。

回想过去某段成功经历（例如赢得比赛、大奖的日子），感受大家的声音（例如此起彼落的赞许、如雷的掌声），观看人们脸上的微笑、欣赏的表情，感受你脚踏在地板的知觉，以及大家向你握手道贺时的触感，最重要的是体会你的内在情绪，感受一股温暖的自信光芒由内而外散发出来。
```

4）渐进式脱敏：你可以找到一些简单的事情，不断地、渐进式地、重复地采取行动，而不是一次极端的经历。

```
1. 每天刻意去接近几位女性，只是问一下时间
2. 先问女性时间，然后再顺带问一句，你今天过得怎么样
3. 最后，你将可以直接走上前去告诉她 “我觉得你很有魅力，想约你出去”
```

5）[觉察](../../2-方法/觉察.md)

7）想象宇宙的浩瀚无垠，你的事情在宇宙面前连一粒沙子都算不上。

## 3）精力不足
如果你身体疲惫不堪，很显然，你是毫无魅力的，在重要事件前不要耗费太多精力。

- 活动前几小时避开任何会耗损你心力的活动，改成可以强化你自信或亲切感的活动。
- 创建你自己的音乐播放清单，放入与你想要达成心理状态相符的音乐。

## 话题 & 沟通
- 多问开放性的问题，而不是只能回答是或否的问题
- 问题应该以正向题材为主，因为人们会把与你谈话时产生的感受，和你这个人做联想
- 内容里最常出现的字也应该是「你」，而不是「我」。打个比方，与其说：「关于这个主题，我在《纽约时报》上读到一篇很棒的文章。」不妨试着说：「你可能会喜欢最近《纽约时报》刊载的一篇相关文章。」或者只是简单的在句子开头加上「你知道……」
- 用对方的词，比如对方很爱打高尔夫球，你不妨用「一杆进洞」来形容成功。若是对方会开船出海，则可以用「船难」代表惨败。

会让人往坏处想的，不只是隐喻而已；某些我们常用的辞汇也有同样的效果。譬如当你告诉某人「没有问题」、「不要担心」、或是「不要犹豫打电话给我」时，他们可能只记住「有问题」、「要担心」、或是「要犹豫」的字眼，而不是你想要支持他们的心意。为了消除这类负面影响，不妨改成这么说：「我们会处理的」、或是「随时想打电话给我都行」

收到别人的赞美时，你的感觉如何？打个比方，当对方说你好看，或是你完成了某件事让他很感动，你的第一个反应是不是想淡化它？对多数人来说，听到赞美，会既高兴，又带点尴尬，不太知道该如何应对。我们多半不是突然害羞起来，就是谦虚的想转移话题：「哦！这没什么……。」
遗憾的是，这么做反而传达一个消息给赞美你的人：他们赞美你是不对的。他们可能因此觉得自己相当愚蠢，甚至产生联想，认为你让他们像个笨蛋。一旦你常让他们有这种感受，很快的他们就不想再赞美你了。不过，若是你让他们觉得恭维你是件好事，他们对自己的感觉也会变好，因而想继续赞美你。下次有人称赞你时，不妨采用以下步骤，巧妙应对：
•  停下来。
•  咀嚼对方的恭维。如果可以，好好享受它。
•  做出你正在消化赞美的表情。让对方感受到他的赞美对你起了作用。
•  感谢他们。说声「非常谢谢你」就可以了，你还能进一步感谢他们如此贴心，或告诉他们，他们的赞美会让你开心一整天

## 握手
**握手能够提升随后交互的品质，产生更高的亲密度和信任**
- 握手时一定要站起来、眼神接触、短暂微笑，手垂直地面，以手肘为轴心晃动，而不是手腕

## 优雅的退场
人们喜欢与富含魅力的谈话高手聊天，但这么一来，对方可能会因聊得太开心而不想放你走。

首先，对话宜尽早结束，别拖太久。不然你和对方都会感到压力而不自在。最简单的方式当然就是有个非走不可、冠冕堂皇的理由──或许是你担任宴会的志工，或是有公务要忙。别人一听到你「有任务在身」，自然就不会预期你能聊太久。

要是你必须打断某一组人的谈话该怎么办呢？或许你必须从某个谈话圈里，拯救出某位有意离开的人；或者你需要介绍其中的人给另外的人认识；又或者是其中一人为了职务必须离开。
碰到这种状况时，你必须集中注意力，带着特别友善的眼神注视对方（参见第九章的技巧）──不是看着你要带走的人，而是被留下来的那个人。这么做是尽量不让对方觉得自己受到排挤，此时尤其要用仁慈型或专注型的魅力来表达。这时候，最好的措辞方式应该像：「真的很抱歉，但克里斯多夫必须先去忙（某某事情）。你可以容许我带他离开吗？」这么说至少让对方感觉决定权在他们手里。

> 影响人们的不是你用的字眼或是说话的内容。事实上，人们只记得跟你讲话时的「感受」

什么样的声音是具有影响力的声音呢？
- 音调与音色：声音压得愈低沉浑厚、共鸣愈大，影响力也愈大。
- 音量：演员登上舞台的第一件事情就是开口试音，调整音量，好让某些区域的观众能够听见他的声音，甚至坐离舞台很远的人也听得见。一个经典的发声技巧是想像自己的声音是一支支的箭矢，讲话时，射向各个区域的听众。
- 速度：以缓慢且规律的速度说话，不时加入停顿点，有助于表达内心的自信。

以下建议能帮助你传达出影响力十足的声音：
- 慢慢说。想像法庭上强烈对比的场面：某个紧张、声音高亢、讲话如连珠炮的青少年，面对着以缓慢、同理心语调声明判决的法官。
- 停顿。自信的人讲话时经常停顿。每说完一个句子──甚至在句子中间，他们便暂停个一、两秒。这显示出他们对自身影响力的信心，相信对方不会打断他们的话。
- 语调下降。问句结尾时语调不是都会上扬吗？现在请你开口念出这一句话，并在句尾上扬语调，听听自己的声音。接着想像法官说出判决：「本案终止审理。」感觉一下这句话结束时的下降语调。在每句话结尾时将语调往下降，有助于传达出你的影响力。若你想让声音听来自信满满，甚至可以在中途就下降语调。
- 注意呼吸。确保你的呼吸深达腹部，并且用鼻子呼吸，而不是用嘴巴，否则会让人觉得你上气不接下气，而且很焦虑。

在此提供一项有效的视觉技巧，帮助你同时传达出影响力与亲和力。假想自己是位牧师，正在主持礼拜。想像自己以浑厚、洪亮的嗓音，展现牧师对于会众的关怀（亲和力），以及一股自诩为上帝代言人的气势（影响力、权威、自信）。
