
# 谁赋予了《易经》哲学含义
主要靠儒家《易传》

《周易》本来的核心是占卜

但后来出现：

《易传》（十翼）

传统认为孔子作，现代学界认为是战国到汉初儒者作品。

其中提出：

> 一阴一阳之谓道。

这是把易经提升为哲学。

《易传》讨论：

- 天地运行
- 阴阳变化
- 人如何顺应规律

所以：

```
周易：
占卜系统

易传：
哲学体系
```
