# 什么是天干地支
天干地支，简称「干支」，是中国古代用于记录时间的一套符号系统。它由十天干、十二地支组合而成。

* 天干：代表天之气，是五行在天的展开
* 地支：代表地之气，是五行在地的展开

# 十天干
## 什么是十天干
十天干是中国古代用于表示时间和 [阴阳](阴阳.md)、[五行](五行.md) 属性的十个符号。分别为：甲、乙、丙、丁、戊 wù、己 jǐ、庚 gēng、辛 xīn、壬 rén、癸 guǐ

## 天干五合
天干五合，是指十天干中，按照阴阳相配、五行关系形成的五组特殊组合。

| 天干    | 合化  |
| ----- | --- |
| 甲 + 己 | 合化土 |
| 乙 + 庚 | 合化金 |
| 丙 + 辛 | 合化水 |
| 丁 + 壬 | 合化木 |
| 戊 + 癸 | 合化火 |

### 如何记忆？
- 相隔为 5
- 合化出的属性的顺序是五行中生的顺序

### 为什么叫五合？
因为这五个组合都是阳干 + 阴干，在阴阳思想里：”阴阳相吸，阴阳交合。“

### 为什么偏偏甲己合，而不是其他？
- 隔五相合：天干五合的理论源于[河图洛书](河图洛书.md)。在河图的构图上："一与六共宗居北方，二与七同道居南方，三与八为友居东方，四与九同道居西方，五与十同德守中央。"对应十天干的顺序：一为甲、六为己，故甲与己合；二为乙、七为庚，故乙与庚合；三为丙、八为辛，故丙与辛合；四为丁、九为壬，故丁与壬合；五为戊、十为癸，故戊与癸合。
- 阴阳相异、五行相克：阳天干只能合阴天干，阴天干只能合阳天干，古人顺应天理，阴阳相合，才可以合化。并且相合的天干，在五行上属于相克关系。如甲己合，甲木克制己土；乙庚合，庚金克制乙木，其他类推。 #重构 这与现实很类似：有张力、有摩擦的两者，反而产生了紧密的吸引力。我理解这里貌似感情是不是就是这样的？其实要有摩擦，要能激起对方的情绪，而不是平淡。

## 天干四冲
天干四冲指的是十天干之间因为阴阳相同、五行相克而产生的冲突关系。土居中央，不列四冲。

| 相冲  | 五行关系 | 阴阳关系     |
| --- | ---- | -------- |
| 甲庚冲 | 金克木  | 阳木 vs 阳金 |
| 乙辛冲 | 金克木  | 阴木 vs 阴金 |
| 丙壬冲 | 水克火  | 阳火 vs 阳水 |
| 丁癸冲 | 水克火  | 阴火 vs 阴水 |

### 如何记忆？
- 木 ↔ 金、火 ↔ 水
- 然后阳对阳、阴对阴

# 六十甲子

## 什么是六十甲子
十天干与十二地支按照固定顺序组合，形成六十个组合，称为「六十甲子」。十天干是 10 个循环，十二地支是 12 个循环，两者重新同时循环，10 和 12 的最小公倍数 = 60

## 第一个甲子年是什么时候？
传统上认为甲子年是从黄帝纪年开始计算的。传说黄帝元年为公元前 2697 年。

## 如何计算一个年份是什么干支？
天干 = (年份 - 4) mod 10，余数中 0 代表甲
地支 = (年份 - 4) mod 12，余数中 0 代表子

所以 2026 年，天干余 2，为丙；地支余 6，为午，所以为丙午年。

# 历法
现在我们的历法是阴阳合历。

## 阳历
阳历分为公历和干支历（就是天干地支）。阳历不是老百姓可以观测到的，而是古代的 [巫](../0-条目/字/巫.md) 根据太阳的变化计算出来的。

## 阴历
阴历就是农历，是根据月亮来判断的，现用于渔业和传统节日
