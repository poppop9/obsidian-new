# 思想来源
天人感应建立在[阴阳](阴阳.md)、[五行](五行.md)思想基础之上。

# 什么是天人感应
天人感应是[汉代儒学（经学）](../../50-Maps%20old/02-🤔%20哲学/中国哲学/秦汉哲学/汉代儒学（经学）.md)中的重要思想，由[人-董仲舒](../0-条目/人/人-董仲舒.md)将阴阳五行与儒家的政治伦理结合，形成了天人感应体系。

天（自然、宇宙秩序）和人（尤其是统治者）之间存在对应关系，人的行为会影响天地变化，天地也会通过各种现象回应人的行为。

```
皇帝德行好
      ↓
政治清明
      ↓
天地和谐
      ↓
风调雨顺
```

```
皇帝失德
      ↓
政治混乱
      ↓
天地失调
      ↓
灾害、异象出现
```
