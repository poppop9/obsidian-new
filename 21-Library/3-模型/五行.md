# 什么是五行
五行本质上是古人用五种基本属性，对自然、社会、人体变化规律进行解释的一套分类模型。分别指：木、火、土、金、水。描述的是阴阳运动过程中呈现的五种不同阶段和状态。

**阴阳 & 五行的关系**：阴阳是五行的根本，五行是阴阳运动的具体表现。

# 五行的发展
## 1. 五材阶段：物质分类
五<span class="va-annotation va-color-blue va-place-auto" data-va-note="运行、变化、运动方式。" data-va-id="va-ms2i1mbi-xi9jmq">行</span>最早与古人对自然物质的认识有关，这一阶段的“五”主要是一种物质分类，早期的“五材”主要指：金、木、水、火、土五种基本材料。

## 2. 五行阶段：自然规律模型
随着思想发展，五行逐渐从“五种物质”转变为解释自然变化规律的模型。五行不再只是具体物质，而代表五种不同的属性和变化关系，并发展出相生、相克，用于解释季节变化、气候运行、万物生长变化。

## 3. 阴阳家发展：宇宙运行模型
战国时期，[阴阳家](../../50-Maps%20old/02-🤔%20哲学/中国哲学/先秦哲学（诸子百家）/阴阳家.md) 进一步发展五行思想。阴阳家将五行从自然分类提升为解释天地运行的宇宙模型。五行开始用于解释天地变化、四时运行、方位关系、阴阳消长。

## 4. 邹衍发展：历史解释模型
[人-邹衍](../0-条目/人/人-邹衍.md) 将五行理论进一步应用到历史领域，提出 [五德终始说](五德终始说.md)

## 5. 董仲舒发展：政治伦理模型
汉代以后，[汉代儒学（经学）](../../50-Maps%20old/02-🤔%20哲学/中国哲学/秦汉哲学/汉代儒学（经学）.md) 吸收阴阳五行思想，其中 [人-董仲舒](../0-条目/人/人-董仲舒.md) 将阴阳五行、儒家伦理和天命思想结合起来，形成 [天人感应](天人感应.md)

## 6. 中医发展：人体系统模型
五行后来进入中医体系，用于解释人体内部关系。

## 相生
五行中相邻为生，表示一种促进、滋养关系。木 → 火 → 土 → 金 → 水 → 木

**联想记忆**
- 木生火：木材燃烧产生火
- 火生土：东西燃烧后化为灰烬，归于土
- 土生金：金属、矿物蕴藏于土中
- 金生水：古人认为金属表面会凝结水珠，因此说金生水
- 水生木：水滋养树木生长

## 相克
五行中相隔为克，表示一种制约、平衡关系。木 → 土 → 水 → 火 → 金 → 木

**联想记忆**
- 木克土：树木扎根土地
- 土克水：土可以阻挡、吸收水
- 水克火：水可以灭火
- 火克金：火可以熔化金属
- 金克木：金属工具可以砍伐木材

## 案例分析
**口诀**：我克者弱、我生者旺、生我者耗、克我者受压

**水过强，会发生什么？**
- 水克火 → 火变弱：水过强，火被压制，所以力量下降
- 土克水 → 水被土制约：土可以限制水，但是水太强，水冲土，土也会受损。这叫反克、<span class="va-annotation va-color-blue va-place-auto" data-va-note="“侮”是欺侮、反抗的意思。原本 A 克 B，但现在 B 太强了，或者 A 太弱了，导致 B 反过来欺负 A" data-va-id="va-ms2j8il9-q7n56w">相侮</span>
- 水生木 → 木可能变旺：水多会滋养木。但是不是无限增强，如果水过强，木吸收不了，反而成为湿木
- 金生水 → 金被消耗：金是水的来源，水太旺，需要大量金来产生，所以会消耗金
- **你看，一个变了，整个系统都会受到影响**

# 五行的应用
五行不仅是一种关于木、火、土、金、水的分类体系，更是一种通过取象比类认识世界的思维模型。

古人认为，万物虽然形态不同，但都具有相似的运行规律，因此可以将不同领域的事物归入五行体系，通过五行之间的生克制化关系，观察事物之间的联系与变化。

- 自然气候 → 五气
- 时间规律 → [五时](../9-未知/五时.md)
- 空间方位 → [五方](../9-未知/五方.md)
- 外在表征 → [五色](../9-未知/五色.md)
- 声音变化 → 五音
- 药食属性 → [五味](../9-未知/五味.md)
- 气味感知 → 五嗅
- 人体系统 → [五脏六腑](../9-未知/五脏六腑.md)
- 身体组织 → 五体
- 身体窍口 → 五官
- 情志变化 → 五志
