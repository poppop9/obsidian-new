# 什么是五行
五行本质上是古人用五种基本属性，对自然、社会、人体变化规律进行解释的一套分类模型。分别指：木、火、土、金、水。描述的是阴阳运动过程中呈现的五种不同阶段和状态。

**阴阳 & 五行的关系**：阴阳是五行的根本，五行是阴阳运动的具体表现。

# 五行的发展
## 1）五材阶段：物质分类
五行（运行、变化、运动方式。）最早与古人对自然物质的认识有关，这一阶段的“五”主要是一种物质分类，早期的“五材”主要指：金、木、水、火、土五种基本材料。

## 2）五行阶段：自然规律模型
随着思想发展，五行逐渐从“五种物质”转变为解释自然变化规律的模型。五行不再只是具体物质，而代表五种不同的属性和变化关系，并发展出相生、相克，用于解释季节变化、气候运行、万物生长变化。

## 3）阴阳家发展：宇宙运行模型
战国时期，[阴阳家](../../51-Maps/🤔%20哲学/阴阳家.md) 进一步发展五行思想。阴阳家将五行从自然分类提升为解释天地运行的宇宙模型。五行开始用于解释天地变化、四时运行、方位关系、阴阳消长。

## 4）邹衍发展：历史解释模型
[人-邹衍](../0-条目/人/人-邹衍.md) 将五行理论进一步应用到历史领域，提出五德终始说

## 5）董仲舒发展：政治伦理模型
汉代以后，[汉代儒学（经学）](../../51-Maps/🤔%20哲学/汉代儒学（经学）.md) 吸收阴阳五行思想，其中 [人-董仲舒](../0-条目/人/人-董仲舒.md) 将阴阳五行、儒家伦理和天命思想结合起来，形成 [天人感应](天人感应.md)

## 6）中医发展：人体系统模型
五行后来进入中医体系，用于解释人体内部关系。

# 五行的生克制化
五行之间不是独立运行的，而是通过生、克、制、化形成一个动态平衡系统。

![452](https://obsidian-1307744200.cos.ap-guangzhou.myqcloud.com/%E5%9B%BE%E7%89%87/wuxing.png)

## 相生
五行中相邻为生，表示一种促进、滋养关系。木 → 火 → 土 → 金 → 水 → 木

**联想记忆**
- 木生火：木材燃烧产生火
- 火生土：东西燃烧后化为灰烬，归于土
- 土生金：金属、矿物蕴藏于土中
- 金生水：古人认为金属表面会凝结水珠，因此说金生水
- 水生木：水滋养树木生长

## 相克
五行中相隔为克，表示一种制约、平衡关系。木 → 土 → 水 → 火 → 金 → 木

**联想记忆**
- 木克土：树木扎根土地
- 土克水：土可以阻挡、吸收水
- 水克火：水可以灭火
- 火克金：火可以熔化金属
- 金克木：金属工具可以砍伐木材

# 五行的胜复乘侮
胜复乘侮是当某一行力量过度强盛（胜/太过）或过度虚弱（不及），打破了正常的生克平衡，所产生的一系列病理性连锁反应。

- 胜（胜气）：某一行的偏胜过盛。
- 复（复气）：针对“胜”而引起的反击与报复性抑制，属于系统试图恢复平衡的代偿机制（即“有胜必有复”）。
- 乘（相乘）：乘虚而入。力量过强的一行，过分克制本就虚弱的受克者。
- 侮（相侮）：反侮、反克。受克者力量太强，或者克制者太弱，导致受克者反过来欺侮克制者。

一个五行属性发生变化，其他所有属性都会受到影响，但是在做动态分析时，需要抓住影响最大的几个环节。

## 太过
除去其本身受到影响，还有两路受到的影响最大。

- 重克我之所克者
- 反侮克我者

```
水太过

1. 水本身受到影响
2. 重克我之所克者：水克火，火被压制，所以力量下降。
3. 反侮克我者：土克水，土可以限制水，但是水太强，会反过来欺负土，导致土受损。
```

## 不及
除去其本身受到影响，还有三路受到的影响最大。

- 我克者作乱
- 我生者失养
- 克我者来欺

```
木不及

1. 木本身受到影响
2. 我克者作乱：木克土，现在木弱了，无法克制土
3. 我生者失养：木生火，现在木弱了，无法滋养火
4. 克我者来欺：金克木，现在木弱了，金更加欺负木
```

# 五行的应用
五行不仅是一种关于木、火、土、金、水的分类体系，更是一种通过取象比类认识世界的思维模型。

古人认为，万物虽然形态不同，但都具有相似的运行规律，因此可以将不同领域的事物归入五行体系，通过五行之间的生克制化关系，观察事物之间的联系与变化。

- 自然气候 → 五气
- 时间规律 → [五时](../9-未知/五时.md)
- 空间方位 → [五方](../9-未知/五方.md)
- 外在表征 → [五色](../9-未知/五色.md)
- 声音变化 → 五音
- 药食属性 → [五味](../9-未知/五味.md)
- 气味感知 → 五嗅
- 人体系统 → [五脏六腑](../9-未知/五脏六腑.md)
- 身体组织 → 五体
- 身体窍口 → 五官
- 情志变化 → 五志
