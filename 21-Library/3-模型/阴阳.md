# 什么是阴阳
阴阳是中国古代解释世界变化规律的一套哲学模型。“阴”和“阳”最初来源于人们对自然现象的观察：向阳的一面 → 阳；背阴的一面 → 阴。后来逐渐抽象化，用来描述事物中两种相互对立、相互依存、相互转化的属性。

因此，阴阳并不是具体的东西，也不是两种物质或力量，而是一种观察世界的方式：用“阴”和“阳”两个符号，描述事物内部存在的两种相反趋势，以及它们之间不断变化的关系。

# 阴阳的核心特征
## 1. 对立统一
阴阳代表事物中相反而又相互关联的两个方面。二者不是绝对的好坏关系，而是一种相对关系。阴阳之间既存在差异和矛盾（对立），又相互依存、不可分割（统一）。

## 2. 互根互用
- 互根：互为根基，阴阳虽然相反，但不能单独存在。正所谓 [熟语-孤阴不生，独阳不长](../5-未知/熟语-孤阴不生，独阳不长.md)
- 互用：阴阳不仅相互依存，还会互相促进，共同构成完整系统。

例如
- 没有黑暗，就无法定义光明；
- 没有寒冷，就无法理解温暖。

## 3. 此消彼长
阴阳不是静止不变的，而是在不断变化。

例如
- 白天阳气增长，夜晚阴气增长；
- 春夏阳盛，秋冬阴盛。

## 4. 互相转化
阴阳发展到一定程度，会向对方转化。正所谓 [熟语-物极必反](../5-未知/熟语-物极必反.md)。

例如
- 白天发展到极点进入黑夜；
- 寒冷到极点开始转暖。

# 阴阳的发展
## 1. 阴阳的自然阶段（早期）
最初的阴阳主要是一种自然观察概念。古人通过观察日照与背阴、白天与黑夜、四季变化、寒暑交替，发现自然存在规律性的变化，因此用“阴”和“阳”来描述这种变化。

## 2. 阴阳家的发展（理论体系化）
[阴阳家](../../50-Maps%20old/02-🤔%20哲学/中国哲学/先秦哲学（诸子百家）/阴阳家.md) 把阴阳从自然现象提升为解释宇宙运行规律的模型。他们将阴阳变化、五行循环、天地运行、人间政治结合起来，形成一种完整的宇宙解释体系。

## 3. 道家的发展（哲学提升）
[道家](../../50-Maps%20old/02-🤔%20哲学/中国哲学/先秦哲学（诸子百家）/道家.md) 进一步提升了阴阳的哲学意义。例如有无、动静、刚柔、生死都可以理解为阴阳关系。
