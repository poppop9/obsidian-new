- 时间规律 → 五时

- 声音变化 → 五音
- 药食属性 → [五味](../1-概念/五味.md)

- 情志变化 → 五志

# 未整理
相生：
木 → 火 → 土 → 金 → 水 → 木

相克：
木 → 土 → 水 → 火 → 金 → 木

木生火：木材燃烧产生火
火生土：东西燃烧后化为灰烬，归于土
土生金：金属、矿物蕴藏于土中
金生水：古人认为金属表面会凝结水珠，因此说金生水
水生木：水滋养树木生长
