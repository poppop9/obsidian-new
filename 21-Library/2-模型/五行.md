# 谁赋予了“五行”哲学含义
五行最早只是物质分类（早期五材，水火木金土），而后主要是[阴阳家](../../50-Maps/02-🤔%20哲学/中国哲学/先秦哲学（诸子百家）/阴阳家.md)发展，后来[儒家](../../50-Maps/02-🤔%20哲学/中国哲学/先秦哲学（诸子百家）/儒家.md)再吸收。

- [人-邹衍](../0-条目/人-邹衍.md)提出了[五德终始说](五德终始说.md)
- [人-董仲舒](../0-条目/人-董仲舒.md)把儒家伦理、阴阳五行、天人关系结合，形成[天人感应](天人感应.md)

# 未整理
相生：
木 → 火 → 土 → 金 → 水 → 木

相克：
木 → 土 → 水 → 火 → 金 → 木

木生火：木材燃烧产生火
火生土：东西燃烧后化为灰烬，归于土
土生金：金属、矿物蕴藏于土中
金生水：古人认为金属表面会凝结水珠，因此说金生水
水生木：水滋养树木生长
