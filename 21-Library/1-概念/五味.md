# 什么是五味
五味是中医药学用来描述药物或食物进入人体后，其主要作用特点和功能倾向的一种分类方法。包括：酸、苦、甘、辛、咸，后来随着中药的发展，又增加了：淡、涩，但传统上仍以"五味"统称。

**五味描述的不是味觉**
- 五味是一种功能分类，而不是单纯的味觉分类。重要的是它进入人体后的作用特点，不能简单的认为酸就是酸，甜就是甘，辣就是辛。
- 黄芪吃起来并不甜，但属于甘，因为它有补益作用。
- 陈皮带有苦味和辛味，不只是因为尝起来苦，而是因为它能理气、燥湿。
- 五味子归为酸味，因为它的主要作用是收敛固涩。

**五味如何判断**
- 五味并不是通过理论推导出来的，而是古人在长期食用和用药过程中，发现某些物质具有相似的作用特点，于是归纳成不同的"味"。
- 能收敛止汗、止泻的，多归为酸。
- 能补益身体、缓和药性的，多归为甘。
- 能发散行气、促进循环的，多归为辛。

# 五味的分类
## 酸
**作用方向**：向内收、向内固

**特点**：收敛固涩、生津止渴、止汗止泻

**适合**：自汗盗汗、慢性腹泻、遗精遗尿、口干津少

**过用**：收敛太过，影响脾胃运化；胃酸过多者易加重反酸、烧心

**代表**：醋、柠檬、山楂、乌梅、石榴、酸枣、五味子

> 就像你咬一口柠檬，整个人会"缩"起来

## 苦
**作用方向**：向下、向外排

**特点**：清热泻火、燥湿解毒、降逆止呕、降气止咳

**适合**：实热证（上火、口腔溃疡）、湿热证、恶心呕吐、咳嗽气逆

**过用**：容易损伤脾胃阳气，导致食欲下降、腹胀、腹泻、皮肤干燥

**代表**：苦瓜、莲子心、苦菊、苦丁茶、陈皮、杏仁、绿茶

## 甘
**作用方向**：补养、缓和、调和

**特点**：补益气血、健脾和中、缓急止痛、调和药性

**适合**：气血不足、脾胃虚弱、疲劳乏力、病后体虚、疼痛拘急

**过用**：容易生痰生湿、肥胖、消化不良

**代表**：大米、小麦、山药、红枣、蜂蜜、南瓜、红薯、桂圆、枸杞、牛肉、鸡肉

## 辛
**作用方向**：向上、向外发散

**特点**：发散解表、行气活血、化痰散结、开胃醒脾

**适合**：风寒感冒初起、气滞血瘀、食欲不振、痰湿壅滞

**过用**：容易耗气伤津，出现口干咽燥、便秘、筋脉拘急

**代表**：生姜、大葱、大蒜、洋葱、辣椒、花椒、胡椒、薄荷、紫苏、韭菜、芥末、白酒

## 咸
**作用方向**：向下、向内渗透

**特点**：软坚散结、润肠通便、补肾、引药下行

**适合**：便秘、痰核结节、瘿瘤（甲状腺肿）、肾虚

**过用**：容易加重肾脏负担，出现水肿、血压升高、口渴

**代表**：海带、紫菜、海参、海蜇、牡蛎、淡菜（贻贝）、猪血

# 五味与五行
五行：木　对应脏腑：肝、胆
五行：火　对应脏腑：心、小肠
五行：土　对应脏腑：脾、胃
五行：金　对应脏腑：肺、大肠
五行：水　对应脏腑：肾、膀胱

# 五味与五脏
《黄帝内经》认为，五味与五脏之间存在对应关系

```
五味
│
├── 酸 → 一般容易影响肝、胆
├── 苦 → 一般容易影响心、小肠
├── 甘 → 一般容易影响脾、胃
├── 辛 → 一般容易影响肺、大肠
└── 咸 → 一般容易影响肾、膀胱
```

五味对应的五脏只是一般规律，真正具体到某一种食物或药物，还需要结合归经来判断。比如 SUV 一般越野能力较强。Model Y 也是 SUV，但是越野一般。也就是说“SUV 一般越野能力较强”只是一般规律，具体越野能力怎么样，还要看具体车型。

# 未整理
酸味过多 → 肝气收敛太过 → 木太多了就会克制脾土

> 《黄帝内经》："多食酸，则肉胝䐢而唇揭"，吃太多酸的，皮肉会变粗糙，嘴唇会干裂翘皮

苦味过多：泻心火太过，火生不了土，伤脾胃阳气

《黄帝内经》："多食苦，则皮槁而毛拔"
（吃太多苦的，皮肤干枯，毛发脱落）

过量的后果：甘味过多 → 脾被壅滞（塞满了消化不动）→ 生痰生湿 → 同时克制肾水 → 骨骼问题、脱发

《黄帝内经》："多食甘，则骨痛而发落"
（吃太多甘甜的，骨头疼痛，头发脱落）


《黄帝内经》："多食辛，则筋急而爪枯"（吃太多辛的，筋脉拘急，指甲干枯）

```
短期（刚吃）          →          长期（一直吃）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
金气暴涨（辛味刺激）    →    金气耗竭（散光了）
  ↓                              ↓
金过度克木（相乘）        →    金虚，木反侮金
肝受伤                      肺也垮了，肾也干了
```

- **短期**：你吃了大量辛辣，辛味的能量瞬间涌入肺金系统，让金气**暂时膨胀**，像打了兴奋剂一样去砍肝木
- **长期**：这种发散本质是在**透支**肺金的家底，最终肺金自己也垮掉


咸味过多 → 肾负担过重 → 血脉凝涩（现代说就是高血压）→ 同时克制心火 → 心脏问题

《黄帝内经》："多食咸，则脉凝泣而变色"
（吃太多咸的，血脉凝滞，面色发暗）
