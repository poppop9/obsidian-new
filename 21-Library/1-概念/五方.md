# 什么是五方
五方是五行体系在空间方位上的映射，指东、西、南、北、中五个方向。古人认为，空间方位并不是单纯的地理位置，而是与自然变化、季节、阴阳升降以及五行属性相互对应。

# 五方与五行对应关系

| 五行  | 方位  | 特征    |
| --- | --- | ----- |
| 木   | 东   | 生发、成长 |
| 火   | 南   | 炎热、扩张 |
| 土   | 中   | 承载、化生 |
| 金   | 西   | 肃降、收获 |
| 水   | 北   | 收藏、滋润 |

# 五方的含义
## 东方 → 木
东方是太阳升起的方向。木具有向上生长、向外伸展的特点，因此对应东方。

## 南方 → 火
南方在传统观念中属于阳气最盛之地。火具有炎热、向上的特点，因此对应南方。

## 中央 → 土
中央位于四方之中，具有调和、承载的作用。土能够孕育万物，因此对应中央。

## 西方 → 金
太阳西落，万物由盛转衰。金具有收敛、肃杀、变革的特点，因此对应西方。

## 北方 → 水
北方寒冷，水具有向下流动、滋润收藏的特点。因此水对应北方。
