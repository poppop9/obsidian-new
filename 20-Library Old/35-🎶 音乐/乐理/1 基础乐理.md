## 音的名字
音有很多名字：唱名、音名

- 有唱名：do 升do/降rei rei 升rei/降mi mi fa so la xi
- 有音名：C D E F G A B

## 音符
```
全音符 ：音符 - - -

二分音符 ：音符 -

四分音符 ：音符

八分音符 ：底下有一条横线

十六分音符 ：底下有两条横线

三十二分音符 ：底下有三条横线

附点音符 · ：表示前一个音符的一半，比如 1 - · 是一个附点二分音符，如果一个二分音符为 2 拍，那么这个附点二分音符就是 3 拍。但是现在附点二分音符不这么写，一般写作 1 - -
```

⚠️ ：音符和几拍没有关系，四分音符可以是一拍，也可以是四分之一拍。

## 休止符
```
全休止符 ：0000

二分休止符 ：00

四分休止符 ：0

八分休止符 ：0 底下有一条横线

十六分休止符 ：0 底下有两条横线

三十二休止符 ：0 底下有三条横线
```

## 拍号（拍子记号）
```
4/4：读做四分之四，或者叫四四
3/4：表示四分音符当 1 拍，每个小节有 3 拍
6/8：八六
```

## 一拍
什么叫一拍，一下一上就是一拍。

```
\  /
 \/
```

## 升记号 & 降记号
```
#：升记号，表示升半音，比如 #C

b：降记号，表示降半音，比如 bE
```

升降号可以现在音符的左边（最好），也可以写在右边。
