# 落地方案
## Folder
Source：能给你带来思考、洞见、可演化的内容 → 进入 Zettelkasten / Permanent
Reference：纯事实、工具说明、一次性资料 → 放在 Reference

## 分类
Tags 用于广义检索；Links 表达具体关系；Folders 以 PARA 为主。

## Ontology 本体字段
Map 组织视角，Library 保存对象；Map 单向引用 Library，反向关系由双链生成。

### Map 字段

| 字段         | 用途         | 示例       |
| ---------- | ---------- | -------- |
| **children** | 下一级 Map | 易学 → 象数易、义理易 |

### Library 字段

| 字段              | 用途     | 示例            |
| --------------- | ------ | ------------- |
| **related**     | 一般相关   | 阴阳 ↔ 五行       |
| **application** | 被用于哪里  | 五行 → 中医、术数    |
| **developer**   | 由谁发展   | 阴阳 → 阴阳家、道家   |
| **influence**   | 影响了什么  | 五行 → 五德终始说    |
| **part**        | 真实组成关系 | 十神 → 四柱八字     |
| **similar**     | 相似关系   | 成长型思维 ↔ 渐进观   |
| **opposite**    | 对立关系   | 成长型思维 ↔ 固定型思维 |
| **figure**      | 相关人物   | 五行 → 邹衍、董仲舒   |

Library 不写 `parent`、`children`；`source` 写在正文；优先使用准确字段，而不是 `related`。
