# 落地方案
## Folder
Source：能给你带来思考、洞见、可演化的内容 → 进入 Zettelkasten / Permanent
Reference：纯事实、工具说明、一次性资料 → 放在 Reference

## 分类
- Tags：用于广义检索
- Links：用于表达具体关系
- Folders：PARA 为主，知识笔记可轻量使用

## Ontology 本体字段
- LIbrary 笔记是没有 children 的，因为此时就没有包含关系了
- Maps 笔记只有 parent、children，因为 Maps 只有包含关系

| 字段           | 含义   | 推荐判断问题      | 示例               |
| ------------ | ---- | ----------- | ---------------- |
| **parent**   | 上位概念 | 它属于什么？      | 确认偏差 → 认知偏差      |
| **children** | 下位概念 | 它包含什么？      | 认知偏差 → 确认偏差、锚定效应 |
| **related**  | 相关对象 | 它和什么有关？     | 道家 → 道德经、庄子      |
| **similar**  | 相似思想 | 什么东西和它类似？   | 道家 ↔ 佛学          |
| **opposes**  | 对立观点 | 什么观点与它相反？   | 成长型思维 ↔ 固定型思维    |
| **figure**   | 相关人物 | 哪些人物与它密切相关？ | 道家 → 老子、庄子       |
| **source**   | 学习来源 | 我从哪里知道它？    | 《中国哲学史》、文章       |
