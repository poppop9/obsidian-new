# 领导
- 理解领导的三观、做事的风格
- 单独见到领导时，可以问问题【但是不能太高深了，要让领导可以回答的上来】

Q 为什么不能得罪直属领导？
A 因为他可以直接左右你的机遇和风评。

Q 单位不给请假怎么办？
A 说自己家里什么什么情况，真来不了。如果还是不给请，那就直接不来，不要去吵架。

Q 不给加班费怎么办？
A 不要威胁领导说违反劳动法，这个不痛不痒，你要么就说一些能影响单位的大证据，让执法机构来讲理，但是要做好找下一份工作的准备。

Q 送礼要怎么说？
A 一点茶水钱，我们做小辈的当然要懂点礼数，领导不要嫌少就好。

# 同事
Q 为什么跟同事永远不要掏心窝子？
A 因为你们是竞争对手。

Q 为什么要和有潜力的同事交朋友？
A 因为他提拔了会照顾你。

Q 为什么不要得罪女同事？
A 因为她们有可能跟某些领导有不一般的关系，而且女生心思敏锐，消息灵通。

# 工作
Q 工作上为什么一定要公事公办，也就是领导不敲板不要干？
A 因为程序就是拿来避责任的，不要嫌麻烦。

Q 程序员如何推卸责任？
A 用户数据问题、网络问题、本地缓存问题。

Q 为什么汇报很重要？
A 你要经常向领导汇报工作进度，反映自己阶段性的成果，让领导感觉大局紧握，最后再让功劳给领导。比如哎呀遇到了时间问题，某某主任说可能是什么问题，试了一下确实是。

# 长辈
Q 遇到不会称呼的长辈怎么说？
A 我不清楚辈数，不敢称呼。
