# 什么是宋明理学
宋明理学是宋、元、明时期形成的儒家哲学体系，也是儒家发展到成熟阶段的重要形态。

相较于先秦儒家主要关注伦理、政治与社会秩序，宋明理学进一步讨论了宇宙本体、人性、心性修养等形而上问题，因此又被称为新儒学。

它并不是新的宗教，而是在继承孔孟儒学的基础上，吸收佛教、道教的思想资源，对儒家进行哲学化重建。

# 宋明理学的由来
唐代以后，佛教和道教发展迅速，在宇宙、本体、心性等问题上形成了较为完整的理论体系。相比之下，儒学逐渐偏重于经学、政治和科举，缺乏系统的形而上学理论。于是宋代儒者开始重新诠释儒家经典，希望回答一系列更深层的问题。

例如：
- 世界为什么如此存在？
- 万物遵循什么原则？
- 人性为什么本善？
- 人为什么会产生私欲与恶？

因此，宋明理学可以理解为儒家的哲学化（形而上学化）。

# 宋明理学的主要流派
三派都承认理、心、气的重要性，但对于三者何者更根本，有不同理解

- **理学**：以「理」为本，认为理先于万物，气只是理的具体实现。
- **心学**：以「心」为本，认为理就在人的本心之中，不必向外追寻。
- **气学**：以「气」为本，认为现实存在的是气，理只是气运行所体现的规律。

因此，它们讨论的并不是三个不同的问题，而是围绕“宇宙与人的根本依据是什么？”这个问题给出了不同的答案。
