# 人为什么会生病
```
先天基础 → 决定身体的易感性
        ↓
后天影响 → 决定疾病是否被激活
        ↓
长期累积 → 形成疾病表现
```

**先天**
- 先天禀赋（体质偏性）：每个人出生时就存在不同的身体倾向，有人阳气偏盛、有人阳气偏弱、有人肺弱、有人脾胃弱
- 遗传因素：现代医学认为，疾病风险部分来自基因
	- 显性遗传：携带基因即可表现
	- 隐性遗传：需要特定条件才表现。例如：一个人携带某种疾病相关基因，但可能终身不发病。

**后天**
- 不知天（不了解自然规律）：不顺四时变化、作息违背昼夜规律、违背季节养生原则
- 不知地（不了解环境影响）：饮食不合地域特点、长期处于湿寒、污染环境、生活环境失衡
- 不知人（不了解自身规律）：不知道自己的体质、不知道身体承受能力、不懂得调节生活节奏、不晓七情六欲

**补充说明**
- 命理体系试图从出生时间解释人的先天倾向
