# 📎 来源
[课-同舟共养](../../01-Sources/课/课-同舟共养.md) 哲舟老师课后回答问题时说：“换个视角，其实我们与周围一切人事物的关系，本质上是与自己的关系。我自己身上是这样发生的，接触过几位女性朋友也是这样，她们一开始很想改变丈夫，改变孩子，想改变别人的这个过程非常痛苦，最后自己发生改变后，丈夫孩子也变了。”

# 💡 核心观点
在任何相互关联的关系系统中，试图直接改变别人往往会激发对方的防御与抵抗。而当你稳定地改变自己在系统中的位置、行为和状态时，整个系统为了重新找到平衡，会被迫随之调整。你是因，关系是果。

# 📐 展开论证
**【关系是系统，不是孤立个体的集合】**

每个人的行为都在回应别人的行为，共同维持着某种稳态。所以很多问题其实是互动模式的产物，你的某些行为（过度承担、反复抱怨、持续退让）正好在维持着你最不满意的那个局面。

> 任何关系（家庭、团队、友情）都像一组咬合的齿轮或悬挂的风铃，你不需要去挨个调整每一个风铃或齿轮。

**【要求别人改变通常无效】**

当你带着"你错了，你要改"的姿态接近任何人时，对方感知到的是否定、控制、威胁，而人在感到被控制时，本能反应是防御、反驳、冷战、阳奉阴违、变本加厉。

**【改变自己，就是改变系统的输入】**

当你改变自己在系统中的行为和位置，原先的互动回路就会断裂、旧的平衡会被打破，整个系统为了维持平衡，就必须跟着你做出调整，系统中的其他人也必须面对新的现实，做出新的反应。

当你把注意力从"盯着别人的问题"收回到"让自己更好"时，至少发生三层变化：
- 减少敌意，降低对方防御——你不再输出"你有问题"的信号，对方的紧张度下降，沟通空间打开。
- 重设责任边界——你不再替别人兜底，对方才有机会真正承担自己的那部分。
- 提升吸引力和尊重——一个人越稳定、越丰富、越不依附，别人越倾向于尊重他，而不是把他当成可以无限消耗的人。

> 你变柔软了，别人就不需要铠甲了。

# 📌 应用与示例
**家庭：总是包揽家务又不断抱怨的妻子**
- 原模式： 妻子全包家务 → 抱怨 → 家人嫌烦但不改 → 妻子继续兜底 → 循环。抱怨没有改变结构。
- 改变自己： 停止抱怨，明确划分责任，只做自己该做的，把时间还给自己。允许混乱发生。
- 结果： 家人一开始不适应，但最终要么分担，要么承担不分担的后果。关系进入新平衡。

**职场：总是替同事救火的人**
- 原模式： 你能力强、责任心重 → 同事习惯把烂摊子丢给你 → 你加班做完又愤怒 → 但下次还是接。
- 改变自己： 停止接不属于你的任务。不带情绪，只陈述事实："这部分是你的交付，我这边需要你按时完成。"
- 结果： 短期内可能有人不满，甚至出现小混乱。但当你不再兜底，责任才会回到该承担的人身上。

**亲子：总想纠正父母的成年子女**
- 原模式： 学了心理学 → 急着"修复"父母 → 父母觉得被冒犯 → 亲子关系更僵。
- 改变自己： 减少无效争论，提升边界感，用自己的生活状态做一个活的证明。
