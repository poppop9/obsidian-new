# 三和弦
三和弦之所以叫三和弦是因为最重要的是三音。

## 大三和弦 M / maj / △
大三度 + 小三度，色彩明亮，有很好的稳定性，常作为乐曲的终止和弦

```
C ➔ 1 3 5
F ➔ 4 6 1
G ➔ 5 7 2
B ➔ 7 #2 #4
B♭ ➔ 7♭ 2 4
```

## 小三和弦 m / min / -
小三度 + 大三度，色彩暗淡，较为稳定

```
Dm ➔ D F A
A♭m ➔ A♭ C♭ E♭
Bm ➔ B D F♯
```

## 增三和弦 aug / +
大三度 + 大三度，色彩诡异，不稳定

增三和弦只有 4 个

```
b6+：b6 1 3 - 可用于 6m7 b6+ 1/5 #4m7-5

b2+：b2 4 6 - 可用于 2m7 b2+ 4/1 5sus4

C+ / E+ / G#+ - C E G#
C♯+ / F+ / A+ - C♯ F A
D+ / F♯+ / B♭+ - D F♯ Bb
D♯+ / G+ / B+ - D♯ G B
```

## 减三和弦 dim / o
小三度 + 小三度

- 色彩非常诡异，不稳定，效果刺耳
- 减三和弦不用学，直接学减七和弦数量少更好学，并且可以替代减三和弦

```
Cdim - C Eb Gb
Ddim - D F Ab
Edim - E G Bb
Fdim - F Ab B
Gdim - G Bb Db
Adim - A C Eb
Bdim - B D F
```

# 七和弦
🔴 七和弦弹法 —— 左手根音低音，右手剩余和弦
- CM7 - 和弦音 1 3 5 7，左手 1 低音，右手 3 5 7
- FM7 - 和弦音 4 6 1 3，左手 4 低音，右手 6 1 3
- G7 - 和弦音 5 7 2 4，左手 5 低音，右手 7 2 4

🔴 **七和弦中最不重要的是五音** —— 因为五音不是色彩音，而且从没有五和弦也可以看出来

## 大七/大大七和弦 M7
大三和弦 + 大七度
- CM7 / Cmaj7 (1 3 5 7) → C G C E G B
- FM7 (4 6 1 3) → Am/F

## 属七/大小七和弦 7
大三和弦 + 小七度
- C7 (1 3 5 b7)
	- 一般用在 4 级和弦前面
	- 如果旋律音中有 7 那就不要弹 b7，要不然会打架
- G7 (5 7 2 4)

## 小七/小小七和弦 m7
小三和弦 + 小七度
- Cm7 (1 b3 5 b7)
- Dm7 (2 4 6 1)
- Em7 (3 5 7 2)
- Am7 (6 1 3 5)

## 半减七/减小七和弦 m7b5/m7-5/ø
减三和弦 + 小七度

```
Bm7b5：7 2 4 6

#Fm7b5：#4 6 1 3
```

Q 为什么半减七和弦标记为 m7b5？
A 因为半减七和弦可以通过小七和弦降低五度音得到

## 减七/减减七和弦 dim7
减三和弦 + 减七度

```
Cdim7 / Ebdim7 / #Fdim7 / Adim7 = C Eb Gb A
Ddim7 / Fdim7 / #Gdim7 / Bdim7 = D F Ab B
Edim7 / Gdim7 / bBdim7 / bDdim7 = E G Bb Db
```

# 三和弦的扩展
## 挂留和弦 sus
将原和弦的三度音替换，一般会替换成 sus2 也就是二度音，或者 sus4 也就是四度音

- sus 全称为 Suspended，意思是悬挂和弦的三度音
- 只标记了 sus，默认是 sus4

```
Csus2：C D G，即为将一级和弦中原本的三度音替换为二度音

Csus4

Fsus2：F G C

Gsus4：G C D
```

## 加音和弦 add
在原有和弦的基础上加上额外的音

```
Cadd9：C E G D

Fadd9：F A C G
```

## 六和弦 ⁶
六和弦是三和弦 + 大六度音，其实就是 add6 和弦。

```
C⁶：C E G A

Cm⁶：C bE G A

Fm⁶：F Ab C D
```

## 六九和弦 69
三和弦 + 大六度音 + 大九度音，可以理解为六和弦 + 大九度音

```
C69：C E G A D
Cm69：C bE G A D
```

## 斜杠和弦 /
- 斜杠和弦是通过改变低音，来改变音响效果，使得和弦的连接更加顺畅
- 斜杠和弦的低音通常是和弦内音，但有时也不一定

```
1/3：C 的第一转位和弦，左手低音从 1 改为 3，弹奏 3 1 3

1/5：C 的第二转位和弦，左手弹奏 5 1 5

5/7：G 的第一转位和弦

F/C
```

# 七和弦的扩展
## 九和弦
⚠️ 3m 、5/7 、7m-5 一般都不升级到九和弦（不等于绝对不用，在其他调式中可能成为常用和弦），因为这些和弦本身功能已经很明确，过度复杂化可能模糊其功能性，和声编配应该服务于音乐表达，不是为了复杂而复杂

1）大九和弦 M9：大七和弦 + 大 9 度音

```
CM9

FM9
```

2）属九和弦 9：属七和弦 + 大 9 度音

```
G9
```

3）小九和弦 m9：小七和弦 + 大 9 度音
- 在大调中，三级和弦不弹奏小九和弦，因为九音 G# 不是音阶调内音

```
Dm9

Am9
```

## 十一和弦
十一和弦是在七和弦的基础上，必须要有十一音，有没有九音无所谓。

```
G11：G B D F C
```

## 十三和弦
十三和弦是在七和弦的基础上，必须要有十三音，有没有九音、十一音无所谓。

```
G13：5 7 2 4 3
```

# 其他扩展和弦
## 附加音和弦
附加音和弦顾名思义就是在原和弦的基础上加音或者升降音，有两种表示方法
- 把附加音写在括号里，例如 (b9) 表示加一个降九音、 (#9,#5) 表示加升九音和升五音
- 用 +/- 号表示升降音，例如 -9 表示加一个降九音、+5 表示加一个升五音

1）属七降九和弦 ⁷(b9) / ⁷-9

```
6⁷-9：6 #1 3 5 b7
```

2）属十一降九和弦 ¹¹(b9) / ¹¹-9

```
5¹¹-9：5 7 2 4 1 b6
```

3）属十三降九和弦 ¹³-9

```
6¹³-9：6 #1 3 5 #4 b7
```

4）属七升五和弦 ⁷+5

```
6⁷+5：6 #1 4 5
```
