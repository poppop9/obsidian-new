# 易经的历史
《周易·系辞》：近取诸身，远取诸物。意思是：观察世界，可以近处从自身寻找规律，也可以远处从自然万物寻找规律。

易经是诸子百家的共同源头，它比儒、道、法、佛都更早，是中国思想的底层操作系统

易经教你现在是什么阶段、该进还是该退、该刚还是该柔

易经其实有三本：《归藏》《连山》《周易》，不是对同一道题给出了三个互相矛盾的答案，更准确地说，它们是同一个大系统的三个侧面/切入点，看问题的角度不同，看到的景象不同，但描述的是同一个世界
- 你从山顶看风景（连山）
- 你从地面看风景（归藏）
- 你从天空看风景（周易）

万物从山中涌出，万物最终归藏于地，万物就这样运行不息

《易传》是孔子对《周易》的系统解释 + 哲学化提升

# “易”是什么意思
易有三义。变易、不易、简易。

- 变易：天地万物现象没有永远固定不变的状态，一切都处在不断的变化之中。
- 不易：虽然现象不断变化，但变化背后存在相对稳定的规律。
- 简易：天地万物的变化虽然极其复杂，但可以用一些简单的基本原则来把握。比如毛笔和筷子，结构简单，但是功能却能变易无穷。

## 变易的三个原则
- 权不离经：权就是权变的意思，经就是不可以变的规矩。不管怎么变，都不能超越这个规矩，要有原则地应变。一个人如果变来变去，变到没有原则了，别人都会厌恶你；一个人如果死守原则，不知道变通，那谁都怕你。用现代话来讲，每一个人都可以变通，但是不能变得太离谱。每一种改变，都应该看它合理不合理。合理是检验的标准，你变得合理，我们就同意，你变得不合理，我们就摇头。
- 权不损人：所有的权变不可以损害别人。
- 权不多用：常常变，就表示原来的很不成熟，就说明你的规矩有问题，要不然为什么会常常变呢？我们今天最大的毛病，就是喜欢求新求变。要记住，变有百分之八十是错误的，天下事不如意者十常八九。我们好不容易找到一个规矩，不要乱变。

---

天、地、人三才中，天是变易，人是交易，地是不易。
- 天是变得最快的，天象无时无刻不在变，尤其是春季的天，说变就变。
- 地是不变的，地一变，人就受不了了，六级大地震只是轻轻变一下，几万人的性命就没有了。
- 人最难。人变也挨骂，不变也挨骂。

> 所以我们慢慢就知道，一切都要变是非常危险的观点。
