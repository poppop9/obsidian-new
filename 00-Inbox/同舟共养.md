- [x] **三个维度的觉察 & 注意事项**
	- 第一层 身体觉察（最基础）：随时随地想起来就扫描一下身体。肩膀紧不紧？哪里有点酸、有点堵？感觉到了，就安抚一下，揉一揉
	- 第二层 情绪觉察（进阶一点）：问自己，我现在是什么情绪？平静？烦躁？开心？有点慌？练久了，从情绪产生到你能觉察到，这个时间差会越来越短
	- 第三层 念头觉察（最难）：念头是脑子里一闪而过的东西。比如“他是不是对我有意见”、“我是不是又做错了”，大多数人都是直接产生“他就是不喜欢我”，而念头觉察是“哦，我现在在觉得他不喜欢我”
	- 注意：看见，但不评判。你只要看见，你就有了选择权。你越是能接纳自己，这些东西反而消逝的更快。
		- 看见身体紧了，而不是“我怎么又紧张了”；
		- 看见情绪了，而不是“我不该生气”；

- [x] **人为什么会生病**
	- 有先天原因 + 后天原因
	- 先天：命理 + 遗传（显性 + 隐性）
	- 后天：三不知（上不知天文，下不知地理，中不知人事） + 不晓七情六欲
	- 先天和后天会相互影响，比如你也能携带有某个疾病的隐性基因，正常是不会显现出来的，但由于你的后天，可能会使得你的隐性基因显现出来。

- [x] **解释“巫”这个字**
	- “巫”上下两横，左右两个人，就是能沟通天地、阴阳的人
	- “巫”在古代是首领的称呼，为什么他能当首领呢？因为他知道天地的节律，他可以以此知识指导大家农耕
	- 为什么“巫”在现在指的是玄乎？可能在古代，巫不想让这些知识在老百姓之间流传，所以整了很多形式来掩盖，以此让大家觉得很玄乎

- [x] “一问三不知”是哪三不知：本义出自《左传·哀公二十七年》：“君子之谋也，始、中、终皆举之，而后入焉。今我三不知而入之，不亦难乎？”指的是事情的起因、经过和结果都不知道。老师说的“上不知天文，下不知地理，中不知人事。”是一种民间的引申说法
- [x] 老师课上说“一个人可能只有手心没有手背吗，不可能吧，只要你说哪一面是手心，那手背也就产生了。”这句话可以用来佐证阴阳之间的关系。

**课间提问**
1. 湿气是什么？—— 运化水湿的整个系统出现问题，导致水湿废物在体内阻塞滞留，这些废物就叫做湿气。
2. 湿气的来源？—— 来源于吃下去的食物和外部的风湿。（我是有鼻窦炎 + 鼻后滴漏的，自己的感受是晚上吹风扇跟不吹风扇的差距，不吹风扇的话明显第二天早上身体会轻盈并且喉咙的痰会少，也有听过“风邪”的概念，我觉得风里可能也会带有湿气吧。）
3. 湿气如何祛除？
	1. 🤔 嗯，如果是脾胃运化不动了，我觉得首先是减轻脾胃负担，不要吃太多吃撑，适量即可，而且要吃易消化的食物，让脾胃把之前的垃圾运化干净。
	2. 少吃生冷食物，多吃温热食物，脾阳升了才能运化食物。（我自己的实践是发现吃兰州拉面对我的病好像有帮助，哈哈哈，因为可能兰州拉面的汤底有很多温热性质的材料）
	3. 在饮食的比例上多吃碳水，少吃蛋白质。我之前看过一个视频说西方人适合的高蛋白饮食，东方人适合高碳水饮食。（这个我自己目前还在实践）
	4. 运动。有句话说“动则升阳”，而且还说“脾主肌肉”，刺激肌肉应该可以达到健脾的效果。
	5. 刷视频还有听过“思伤脾”，可以就是要脑子少想，身体多动吧。（本人脾胃不太好，可能大数据原因吧，这关于脾胃的视频也是经常刷到 🤣。）
	6. 还有从上节课的五行对应五脏来说，我觉得通过对其他器官的作用也可以间接的达到健脾的效果。（刷视频听过什么“母 …… 令子实”之类的，还没深究，不太懂，需要学习。）
